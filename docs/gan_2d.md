# 纯 C GAN：生成八簇二维点

## 目标与验收

从二维点开始学习对抗训练，便于直接观察分布变化。`src/ml/14_gan_2d.c` 手写两个 MLP 的前向、反向和 Adam，不依赖外部计算框架。复用软件画布、BMP 独占导出与双输出日志；没有窗口、模型持久化或图像 GAN。

## 1. 两个网络分别做什么

```text
z ~ N(0,I)，两维
生成器 G：2 → 16(tanh) → 16(tanh) → 2(线性坐标)
判别器 D：2 → 16(tanh) → 16(tanh) → 1(logit)
D概率 = sigmoid(logit)
```

G 有354个参数，D 有337个有效参数。教学实现为两者各保留354个数组槽，D未使用的第二输出行和偏置梯度恒为零。权重以 `[输出][输入]` 行优先存放，缓存和数组由调用方拥有，无动态分配。

真实分布是八个等权二维高斯：中心均匀分布在半径2的圆周上，每个坐标的噪声标准差0.08。每批在线生成真实点，没有固定训练集需要记忆。G只接收独立标准正态噪声，输出不裁切；推理不调用D，也不需要真实样本。

GAN与VAE的差别在这里很直接：没有编码器、逐样本重建目标或KL项；G通过D的判断接收学习信号。[GAN原始论文](https://arxiv.org/abs/1406.2661)介绍了这种生成器与判别器的对抗学习框架。

## 2. 损失与非饱和目标

代码从logit计算稳定二元交叉熵：

```text
BCE(a,y) = max(a,0) - y*a + log1p(exp(-abs(a)))
dBCE/da = sigmoid(a) - y
L_D = mean_real BCE(D_logit(x),1) + mean_fake BCE(D_logit(G(z)),0)
L_G = mean_noise BCE(D_logit(G(z)),1)
```

D的两组均值相加，不再除以2，因此理想均衡附近参考值为 `2*ln(2)`；G参考值为 `ln(2)`。它们不是需要强制达到的训练门槛。

G使用非饱和目标 `-log(D(G(z)))`，不是原始极小极大生成器目标 `log(1-D(G(z)))`。当D很确信是假时，非饱和目标的logit导数接近-1，能保留学习信号。给G的BCE目标1表示“推动D将生成点判真”，不会把真实样本错误标记成假。

损失不要求逐步下降：一个网络更新后会改变另一个网络的目标。单独看到G损失小或D输出约0.5，都不足以证明生成分布准确。

## 3. 交替更新与冻结

每步按以下顺序执行，批量32，固定6000步：

1. 保持G参数不变，生成假点；累加真实标签1、假标签0的D梯度，再更新D一次。
2. 重新抽取G噪声，使用更新后的D；将D输入梯度回传至G，更新G一次。

第二阶段的链为 `dL/dlogit → D两层tanh → dL/d生成坐标 → G两层tanh → G参数与噪声`。**冻结D参数仍需经过D反向传播**；若切断D输入导数，G就没有学习信号。代码把D参数导数写入临时数组并丢弃，不调用D优化器。

两网络各自拥有Adam一阶/二阶矩与beta幂，学习率0.001、beta1=0.5、beta2=0.999；批量平均后全局L2裁剪5。先检查候选值，再统一提交网络和优化器，非有限值失败不部分修改。每步断言非目标网络完全不变。

## 4. 可重复性与数值验证

初始化种子G=42、D=43；训练真实点2025、D阶段噪声3025、G阶段噪声4025分别持续推进。中间监测使用独立种子5025，最终评估6025；固定步数输出最终模型，不按最终评估选检查点。绘图真实点7025、生成噪声8025，不消耗训练状态。

Box-Muller使用开区间均匀数，避免 `log(0)`。所有数值差分固定同一输入和参数，仅扰动被检查量；D对两种标签分别检查全部槽与输入，G检查全部参数和噪声的完整复合损失。无效D尾槽的导数也检查为零。

边界断言覆盖logit±1000的稳定损失、采样可重复、固定D样本单步下降、固定D的G单步下降及NaN更新不改状态。训练损失与输出须保持有限。

## 5. 生成质量与模式崩塌

用1024个独立生成点统计三项诊断：平均最近簇中心距离；距离不超过0.3的有效点比例；每个簇至少8个有效点时计作覆盖。八个计数只统计有效点，不含簇之间的过渡点。

这些诊断用到了当前已知合成分布的中心，适用于教学，不是通用GAN质量指标。距离小但只覆盖一簇仍属于模式崩塌；覆盖8簇也不代表权重均衡、方差正确或没有离群点。另输出独立真实/生成点上的D平均概率，但不把0.5当作质量证明。

GAN生成噪声没有逐点正确答案，不能用VAE式“原图与对应重建MSE”评价。更换数据或比较算法时需使用独立评估、多种初始化及完整分布指标。

## 6. 四张图片

均为320×240，坐标视图为 `[-3,3]×[-3,3]`，y向上；非有限或视图外点忽略，统计仍包含离群点。

- **gan-before**：绿色真实点，橙色初始G输出，通常集中在原点附近。
- **gan-after**：同样的真实点和噪声，替换为训练后G，便于直接比较。
- **gan-discriminator**：训练后D概率场，红色接近1、蓝色接近0；不是密度图，视图外或无数据区的颜色没有真实性保证。
- **gan-latent-grid**：25×25规则潜在坐标，从-2到2，G输出以红/绿分量编码输入列/行，观察潜在空间折叠和簇之间过渡；它不是随机采样分布。

## 8. 学习练习

先跟踪一个假点的D输入导数，再观察G更新前后这个点的位置。将原始极小极大目标与非饱和目标在很负的logit处比较。每次只修改一种因素，例如D/G学习率比、每步更新次数或网络宽度，并比较每簇计数与多个种子；不要用最终评估选择配置后仍称其为独立测试。八簇点之后再考虑图像GAN与卷积结构。
