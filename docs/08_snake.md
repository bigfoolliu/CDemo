# 终端贪吃蛇

运行 `make snake`，或编译后运行 `./build/games/snake`。

这是实时版本：方向键或 W/A/S/D 转向，无需回车；每 200 毫秒自动前进一步，直到下一次转向。Q、Ctrl+C 或 Ctrl+D 退出。需要支持 ANSI 的交互终端；终端输入与计时使用 POSIX API，适用于 macOS/Linux，无第三方库。

- `@` 是蛇头，`o` 是身体，`*` 是食物，`#` 是墙。
- 吃一个食物增长一格、加一分，食物始终生成在空格。
- 不能直接掉头，每个移动周期只接受一次有效转向。
- 撞墙或撞到身体死亡，记录得分，一秒后自动开始新一局；填满棋盘获胜后也自动重开。
- 显示当前分数、历史最高分、已记录局数及最近五局分数。未知按键不改变方向，蛇继续前进。

## 得分持久化

默认向当前目录的 `snake_scores.log` 追加每局分数，每行一个整数；启动时读回历史记录，保留此前数据。死亡或获胜时记录，主动退出时也记录当前局；在重开等待期退出不会重复记录。

```sh
./build/games/snake build/my_scores.log # 使用自定义历史文件，父目录需已存在
cat snake_scores.log                   # 查看完整历史
```

默认历史文件已被 Git 忽略。加载时跳过非法或超出棋盘最大分数的记录；文件读写失败会明确报错，不静默丢失得分。该简易文件格式用于单实例本地游戏，不提供多进程写入锁。

## 实现与测试

通过 `termios` 关闭逐行输入和按键回显，`select` 等待输入或下一次移动，`CLOCK_MONOTONIC` 保证按键不会重置移动计时。方向键转义序列可以跨读取解析。信号处理器只设置退出标志，由主循环保存分数并恢复终端；正常退出也恢复光标和原屏幕。

共享规则 `src/games/snake_env.h` 用定长数组保存蛇身，头部位于索引 0；`snake.c` 负责人工游戏循环，`snake_terminal.h` 负责终端输入和渲染。一步移动先计算新位置并检查碰撞，再移动数组元素。不吃食物时尾部会离开，因此允许蛇头进入旧尾格。增长到棋盘容量后不再生成食物，避免空格数为零时求模。人工与 [深度强化学习模型](62_snake_ai.md) 使用同一个规则模块。

`step` 失败时不修改游戏状态；`place_food` 仅在存在空格时调用。`rand` 的取模采样适合教学游戏，不保证严格均匀。规则测试可通过 `./build/games/snake --test` 执行，已接入 `make test`；`make run` 不会启动交互游戏。

`make test-snake-terminal` 使用 Python 3 标准库创建伪终端，验证实际自动移动/重开、方向键、得分追加、Q/Ctrl+C 退出及终端恢复；不修改用户得分文件。
