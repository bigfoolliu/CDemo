# 机器学习、深度学习与大模型补充学习框架

> **文档状态：框架草稿。** 本文先确定学习范围、章节结构与实践方向；公式推导、逐步手算、完整代码和详细验收标准待后续补充。已有主路线见[从零到大模型智能体（agent）的学习路线](70_机器学习到智能体学习路线.md)。

## 1. 学习目标

补齐现有案例之间的知识连接，重点理解模型训练、评估、保存、推理和部署的完整过程。优先用 C 实现小型核心机制，再按需要用 Python 处理数据、绘制结果或连接成熟工具；每个专题采用“数学推导、手算示例、代码映射、实验验证、边界讨论”的学习方式。

## 2. 经典机器学习补充

### 2.1 高斯混合模型（Gaussian Mixture Model，GMM）与期望最大化（Expectation-Maximization，EM）

- **目标**：理解软聚类、似然和潜在类别。
- **数学待补**：高斯分布、混合概率、责任度、期望最大化算法的 E 步与 M 步。
- **C 实践待补**：二维小数据集上的高斯混合聚类；与 K-means 对照。
- **验收待补**：手算一次责任度与参数更新；检查似然变化和退化协方差。

### 2.2 统计可靠性与分布外（Out-of-Distribution，OOD）评估

- **目标**：区分单次分数与可重复的泛化结论。
- **数学待补**：Bootstrap 重采样（bootstrap resampling）、置信区间（confidence interval）、配对比较、随机种子波动。
- **C 实践待补**：为现有模型比较案例生成区间估计和失败样本报告。
- **验收待补**：覆盖小样本、类别不平衡和分布变化。

### 2.3 模型与预处理参数持久化（model persistence）

- **目标**：确保训练结束后可以独立加载模型并复现推理。
- **内容待补**：二进制格式、版本、字节序、参数校验和失败恢复。
- **C 实践待补**：保存模型与标准化统计量，加载后逐样本比较预测。

## 3. 深度学习补充

### 3.1 自监督学习（self-supervised learning）与对比学习（contrastive learning）

- **数学待补**：正负样本、相似度、温度参数和 InfoNCE（Noise-Contrastive Estimation）损失。
- **C 实践待补**：二维合成数据上的表示学习与嵌入可视化。

### 3.2 策略梯度（policy gradient）与行动者-评论家（Actor-Critic）

- **数学待补**：策略梯度、回报、优势函数，以及近端策略优化（Proximal Policy Optimization，PPO）裁剪目标。
- **C 实践待补**：从 REINFORCE 到 Actor-Critic；与已有贪吃蛇深度 Q 网络（Deep Q-Network，DQN）对照。

### 3.3 扩散模型（diffusion model）

- **数学待补**：前向加噪、反向去噪和噪声预测损失。
- **C 实践待补**：先在二维点分布上演示逐步加噪与采样，再考虑小型图像。

## 4. 大语言模型与智能体（agent）补充

### 4.1 预训练数据与规模规律（scaling laws）

- **内容待补**：数据清洗、去重、数据泄漏、训练规模与验证方法。
- **C 实践待补**：构建可复现的小语料管线，记录数据来源、划分与训练预算。

### 4.2 推理效率（inference optimization）

- **内容待补**：键值缓存（key-value cache，KV cache）、权重量化（weight quantization）、批处理、推测解码（speculative decoding）及其成本权衡。
- **C 实践待补**：比较全量重算与缓存推理；测量精度误差、内存和运行时间。

### 4.3 指令微调与偏好对齐

- **内容待补**：监督微调（supervised fine-tuning，SFT）、低秩适配（Low-Rank Adaptation，LoRA）、奖励模型（reward model）、直接偏好优化（Direct Preference Optimization，DPO）与基于策略优化的对齐方法。
- **C 实践待补**：从目标 token 掩码开始，在极小模型或数值例子上逐项验证。

### 4.4 智能体（agent）可靠性与安全

- **内容待补**：工具权限、参数校验、预算、超时、循环限制、提示注入（prompt injection）和轨迹评测。
- **C 实践待补**：构建固定任务集与失败回放，分别统计任务成功率、工具选择和检索质量。

## 5. 选修专题

根据兴趣补充图神经网络（Graph Neural Network，GNN）、时间序列预测（time-series forecasting）、目标检测（object detection）与图像分割（image segmentation）、多模态模型（multimodal model）和可解释性（interpretability）。完成标准与详细案例待定。

## 6. 建议学习顺序

1. 模型与预处理参数保存、加载及推理一致性。
2. 高斯混合模型与期望最大化，再补统计可靠性评估。
3. 策略梯度与自监督表示学习。
4. 扩散模型。
5. 按[大模型学习路线](70_机器学习到智能体学习路线.md)完成分词、预训练、推理、微调、检索增强生成（Retrieval-Augmented Generation，RAG）与智能体（agent）。
6. 补充推理效率、Agent 安全与综合评测。
7. 按个人方向选择选修专题。

1. 问题定义、适用场景与前置知识。

3. 带具体数字的完整手算过程。
4. 数学步骤与 C 源码的逐项映射。
5. 实验设置、基线、指标与结果解释。
6. 边界情况、常见错误、练习题与参考答案。
