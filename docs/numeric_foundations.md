## 1. 数组形状与行优先存储

向量是有序数列，矩阵是按行列组织的数。内存实际是一维连续数组，形状由程序额外记录。

```text
A (2×3) = [1 2 3]      内存：[1, 2, 3, 4, 5, 6]
          [4 5 6]      A[row,column] = data[row * columns + column]

B (3×2) = [ 7  8]
          [ 9 10]
          [11 12]
```

`Matrix` 的 `capacity` 是可访问的 **double 元素数**，不是字节数。形状要求 `rows*columns <= capacity`。先检查乘法是否溢出，再计算元素数与字节数，不能先乘再检查。

矩阵乘法的输入形状为 `(m,k) × (k,n)`，输出为 `(m,n)`：

```text
C[row,column] = Σ A[row,k] * B[k,column]
C[0,0] = 1*7 + 2*9 + 3*11 = 58
A×B = [ 58  64]
      [139 154]
```

一行向量乘一列向量得到标量，就是点积：`[2,3]·[4,5] = 23`。

转置交换行列：`A^T = [[1,4],[2,5],[3,6]]`，形状变为 `3×2`。逐元素相加则要求形状完全相同：`A+A = [[2,4,6],[8,10,12]]`。逐元素运算不会自动等同于矩阵乘法，也不实现广播。

## 2. 存储所有权和失败行为

`matrix_create` 接收空描述符，分配存储并显式初始化浮点零；`matrix_destroy` 释放内存并恢复空状态，可以重复调用。拥有者必须唯一，不能复制含指针的描述符后分别释放；测试中的栈缓冲区描述符只用于借用访问，不调用销毁。

分配器参数通常传 `calloc`。测试传入始终返回空指针的 `fail_allocate`，安全、确定性地模拟分配失败。创建失败保留原描述符，入口明确报错，并释放已经创建的其他矩阵。

运算先检查描述符、形状和容量，失败不修改输出。乘法和转置禁止输入输出存储重叠，因为写入会破坏尚未读取的数据；逐元素相加允许完全原地计算。部分重叠存储由调用方禁止，程序只检查相同的起始指针，不假装能验证任意指针的实际容量。

本例仅处理有限且中间运算不溢出的小数据。这是接口前提，矩阵函数不提供通用的 NaN、无穷或数值溢出恢复机制。

## 3. 两输入线性模型的前向计算

输入、权重都是长度 2 的向量；偏置、预测、目标和损失都是标量：

```text
x = [1,2]，w = [0.5,-0.25]，b = 0.1，目标 y = 1
预测 p = w0*x0 + w1*x1 + b = 0.1
误差 e = p-y = -0.9
损失 L = e² = 0.81
```

一般均方误差为 `MSE = Σ(p_i-y_i)²/N`；此处只有一个样本，因此 `N=1`。本例不乘 `1/2`，所以导数带系数 2。这个线性模型没有激活函数，不应将预测值与隐藏层激活值混为一谈。

## 4. 偏导数与链式法则

偏导数表示只改变某个参数时，损失如何变化。链式法则将“参数影响预测”和“预测影响损失”串起来：

```text
dL/dp = 2*(p-y) = -1.8
dp/dw0 = x0 = 1       → dL/dw0 = -1.8
dp/dw1 = x1 = 2       → dL/dw1 = -3.6
dp/db  = 1            → dL/db  = -1.8
```

`LinearStep` 保存本次预测、误差、损失和梯度。网络反向传播也需要前向阶段的输入或激活结果；保存哪些量取决于具体层。本例刻意先计算所有梯度，再统一更新参数，避免梯度计算混用不同版本的参数。

学习率 `η=0.05`，更新规则为 `参数 ← 参数 - η*梯度`：

```text
w0 = 0.5   - 0.05*(-1.8) =  0.59
w1 = -0.25 - 0.05*(-3.6) = -0.07
b  = 0.1   - 0.05*(-1.8) =  0.19
重新预测 p = 0.59*1 - 0.07*2 + 0.19 = 0.64
新损失 L = (0.64-1)² = 0.1296
```

这些结果是已知样本上的实现验证，单个样本不能唯一确定三个参数，也不能证明对新数据的预测能力。

## 5. 用中心差分验证梯度

测试对每个参数分别加减 `ε=1e-5`，其余参数保持不变：

```text
数值梯度 ≈ [L(参数+ε) - L(参数-ε)] / (2ε)
```

将数值结果与解析梯度及手算答案对照，避免只用同一套梯度公式验证自己。当前固定小数据采用绝对误差阈值 `1e-8`；更一般的数据需要结合相对误差与数值尺度调整。ε 太大增加近似误差，太小可能使浮点相减丢失有效数字。

## 6. 为什么学习率会改变训练行为

同一样本的下一次误差可推导为：

```text
e_next = [1 - 2η*(x0²+x1²+1)]*e = (1-12η)*e
```

| 学习率 | 误差倍率 | 行为 |
| --- | --- | --- |
| 0.05 | 0.4 | 同号收敛，误差幅度缩小 |
| 0.12 | -0.44 | 误差交替正负，幅度缩小，损失下降 |
| 0.20 | -1.4 | 误差交替正负，幅度增大，损失上升 |

对这个固定单样本，`0 < η < 1/6` 时误差收敛；边界 `η=1/6` 保持误差幅度。这个阈值依赖输入和损失定义，不能直接套用于其他数据或神经网络。更复杂训练尤其小批量训练不要求每步损失下降。
