# 阶段 2：二维 MLP、小批量训练与决策边界

源码：`src/ml/07_mlp_2d.c`。在 [XOR 案例](xor_mlp.md) 的基础上增加第二个隐藏层，学习 ReLU、批量梯度、打乱样本、Adam、独立评估和可视化。计算仅使用 C 标准库与数学库；BMP 导出复用已有软件绘图核心，不需要 SDL。

## 运行与调试

在仓库根目录运行：

```sh
make mlp-2d                  # 训练、比较优化器，并导出六张决策边界 BMP
make test-mlp-2d             # 数值测试与短训练，不生成图片
make sanitize-mlp-2d         # 地址和未定义行为消毒器检查
./build/ml/07_mlp_2d         # 只显示训练结果，不写文件
```

程序自动接入默认构建、`make ml`、`make test` 和 `make lint`。正常输出每 40 轮显示一次训练与验证指标，不生成持久日志；将来若增加文件日志，路径必须位于 `logs/`。

VS Code 选择 `C: ml/07_mlp_2d.c` 后按 F5，默认带 `--export`，训练后可打开图片观察。在 `network_backward` 中观察 `delta2` 和 `delta1`；在 `batch_gradients` 中观察梯度累加；在 `network_update` 中观察 Adam 的矩估计。普通构建使用 `-O2` 加快运行，独立调试构建使用 `-O0`。

## 1. 数据与三个集合

输入是二维坐标，范围在 `[-1,1]`。生成两个平衡类别：

- 标签 1：半径 `0..0.55` 的内圆盘。
- 标签 0：半径 `0.75..1` 的外圆环。

角度均匀，半径平方均匀，使每类在其区域内按面积均匀采样。两个区域之间留有间隔，适合首次观察非线性分类；间隔内没有训练或评估样本，不能据此判断那里存在唯一正确边界。

| 集合 | 样本数 | 种子 | 用途 |
| --- | --- | --- | --- |
| 训练 | 256 | 2025 | 计算梯度、更新参数 |
| 验证 | 128 | 2026 | 选择最佳轮数和优化器 |
| 测试 | 256 | 2027 | 配置与模型选择结束后进行最终评估 |

三个集合使用分开的伪随机状态，来自相同生成规则。输入尺度预先定义，不从测试集计算标准化参数。数据不被原地打乱，训练只打乱下标数组。

这比仅验证训练样本更完整，但仍只证明模型在这个简单合成分布上的表现。改变半径、采样方式或加入噪声后，需要重新评估。

## 2. 结构、形状与初始化

```text
x(2) → W1(16×2), b1(16) → ReLU h1(16)
     → W2(16×16), b2(16) → ReLU h2(16)
     → W3(1×16), b3(1) → logit → sigmoid
```

共 `32+16+256+16+16+1=337` 个参数，使用行优先的扁平数组存储。`W1`、`B1` 等枚举给出每块参数的起始位置。缓存保存两层的激活前分数和激活结果。

两层 ReLU 权重初始化为 `[-sqrt(6/fan_in),sqrt(6/fan_in))` 的均匀随机数，其方差为 `2/fan_in`，即 He 均匀初始化。输出层采用方差 `1/fan_in` 的较小尺度；偏置置零。初始化种子 42 与数据、打乱状态分开。

所有模型、数据和优化器缓冲区均为固定容量，不动态分配。接口要求有效指针、正确数组容量和有限数值；这是教学案例，不提供任意形状的张量 API。

## 3. ReLU 与反向传播

`ReLU(z)=max(0,z)`。本例规定正数处导数为 1，负数和零点处为 0。零点数学上不可微，因此数值梯度检查必须避开跨零点扰动。

输出采用稳定 sigmoid 与基于 logit 的二分类交叉熵，仍有 `δ3=p-y`：

```text
dW3[h] = δ3*h2[h]，db3 = δ3
δ2[h]  = δ3*W3[h]*I(z2[h]>0)
dW2[h,i] = δ2[h]*h1[i]，db2[h] = δ2[h]

δ1[i] = Σ_h δ2[h]*W2[h,i] * I(z1[i]>0)
dW1[i,j] = δ1[i]*x[j]，db1[i] = δ1[i]
```

第一层的梯度要累加来自全部第二层神经元的路径。所有梯度计算完毕后才更新参数，不能在层与层之间提前改权重。

## 4. 小批量平均梯度与打乱

一次选取 16 个样本，每个样本在同一版本网络上前向、反向，然后求平均梯度：

```text
g_batch = (g_0 + ... + g_(n-1))/n
参数 ← 参数 - 学习率*g_batch
```

每轮 256 个训练样本共更新 16 次；200 轮共更新 3200 次。最后一个批次如果不足 16，使用实际大小 `n`，不能仍然除以 16。测试使用三个样本验证两样本批与单样本尾批。

每轮 Fisher–Yates 打乱下标；两个优化器均从打乱种子 2028 开始，使用相同的批次顺序。这里的简易伪随机数用于教学复现，不宣称严格统计均匀或密码学安全。

## 5. 从 SGD 到 Adam

先验证 SGD 的 `参数 -= rate*g`，再实现 Adam：

```text
m ← 0.9*m + 0.1*g
v ← 0.999*v + 0.001*g²
m_hat = m/(1-0.9^t)
v_hat = v/(1-0.999^t)
参数 ← 参数 - rate*m_hat/(sqrt(v_hat)+1e-8)
```

`t` 是批次更新次数，不是 epoch。两种矩从零开始，偏差修正通过递乘 beta 的幂实现；epsilon 位于平方根外。本例 SGD 学习率 0.05，Adam 学习率 0.003。

两个优化器共用初始化、数据、批次顺序和轮数预算，分别记录验证损失最低的参数副本，再按最佳验证损失选择其中一个。测试集到此才评估，不能看测试结果后再次换优化器。

这用于理解更新行为，不是优化器性能排名：学习率不同，也没有系统搜索各自最优配置。若恢复 Adam 继续训练，必须保存匹配的矩与步数；当前只选择参数做推理，不实现模型持久化或断点续训。

## 6. 看懂决策边界图片

显式导出后，`exports/` 中各优化器有三张 `320×240` BMP：

- `mlp2d-SGD-initial-...bmp` / `mlp2d-Adam-initial-...bmp`：训练前。
- `mlp2d-*-epoch100-...bmp`：第 100 轮的当前模型。
- `mlp2d-*-best-...bmp`：验证集选择的最佳模型，未必是最后一轮。

文件带时间和序号，独占创建，保留已有图片；导出失败明确报错。普通运行和默认测试不创建图片，也不打开窗口。

背景蓝色表示类 0 概率高，橙色表示类 1 概率高；点中心颜色表示训练标签，白圈便于辨认。左上角是 `(-1,+1)`，右下角是 `(+1,-1)`，y 轴与数学坐标同向；横纵方向分别覆盖相同坐标范围，画布比例会使圆显示为椭圆。

ReLU 网络的 logit 是分段线性函数，因此边界可能呈多边形。图片四角及两类间隔处缺少样本，颜色展示的是模型预测，不是这些区域的准确率。图片只叠加训练点，不把测试点拿来人工调整网络。

## 7. 验证与结果

内置断言验证：

- 数据半径范围、类别平衡、固定种子复现及不同生成状态。
- 两样本平均损失对全部 337 个参数的数值梯度；固定夹具保持两层 ReLU 分支不变，确保全部参数都检查。
- 零点采用导数 0、尾批平均、打乱不丢失或重复下标。
- SGD 更新结果、Adam 前两次恒定梯度更新的偏差修正、极端 logit 的稳定损失。
- 两优化器训练损失下降、验证准确率至少 90%；最终所选模型的测试准确率至少 90%、交叉熵小于 0.2。

固定配置下，SGD 的最佳验证损失约 0.0054，Adam 约 0.0001；验证集选择 Adam，独立测试准确率为 100%，交叉熵约 0.0002。这是一次固定种子的简单任务结果，不保证其他配置相同，也不把训练集准确率当作泛化证据。

绘图、BMP 的裁切与写入失败等通用行为由已有图形测试验证；本例导出需另外显式执行 `make mlp-2d` 观察。

## 练习与下一阶段

1. 跟踪一个批次，解释为何梯度应取平均，以及为何所有样本必须使用相同参数版本。
2. 减少训练样本，比较训练与验证损失；调参使用验证集，最终测试评估前冻结配置。
3. 缩小两类半径间隔或加入坐标噪声，观察边界和独立评估变化。
4. 改变 WIDTH，检查参数数目、初始化尺度和梯度验证；若扰动跨 ReLU 零点，更换平滑夹具，不能删除梯度检查。
5. 分别调整 SGD 和 Adam 的学习率，重复多个种子，不只挑最好的一次运行。

理解这些计算后，再进入阶段 3 的 CNN，学习局部连接、权重共享与卷积核的反向传播。
