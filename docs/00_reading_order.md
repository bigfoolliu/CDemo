# 文档阅读顺序

`docs/` 中的两位数前缀表示建议阅读顺序，并按主题留有编号间隔，方便后续插入教程。各主题路线可以独立学习；第一次接触项目时，建议先读 C 基础，再按兴趣选择图形、机器学习或深度学习路线。

## 推荐起步路线

零基础可以按 `01 → 02 → 03 → 04` 熟悉语言和工具，再阅读 `30 → 31 → 32 → 33` 进入机器学习。想深入神经网络时继续 `50 → 51 → 52 → 53 → 54`；后续按兴趣进入图形模拟、序列模型、生成模型或强化学习。每篇教程也会链接必要的前置内容和对应源码。
