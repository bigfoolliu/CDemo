# 阶段 7：纯 C 小型 Transformer

源码：`src/ml/12_tiny_transformer.c`。这个单层 decoder-only 字符模型展示缩放点积注意力、因果掩码、多头、位置表示、残差、LayerNorm、GELU 及完整反向传播。模型计算只用 C 标准库和 `<math.h>`，没有框架或自动求导；目标是理解核心计算，不是训练实用大语言模型。


默认构建、`make ml`、`make test`、`make lint` 均包含该案例。普通构建使用 `-O2`，调试使用 `-O0 -g3`。默认不写文件；`--log` 自动创建 `logs/ml/`，追加保留旧日志，每行带毫秒时间戳和源码位置，失败返回错误。日志复用含 POSIX 目录接口的项目记录器，网络计算使用 ISO C。`--test` 与 `--log` 互斥，验证必须保持断言启用。

## 1. 模型结构与形状

字符表继续使用 `"abc "`，输入编号0～3；目标是输入字符串的下一个字符。上下文最多16个位置，表示维度16，两个头各8维，前馈隐藏层32维：

```text
字符嵌入 + 可学习位置向量 → x
x → LN1 → Q/K/V → 双头因果注意力 → 输出投影 → 加回x → y
y → LN2 → 16→32 → GELU → 32→16 → 加回y → z
z → 最终LN → 四字符logits → softmax
```

这里采用 pre-LayerNorm：先归一化再进入注意力/前馈分支；残差保留原输入路径。最终还做一次 LayerNorm。前馈和输出投影逐位置使用共享参数，不跨位置混合；只有注意力汇聚不同位置的信息。

| 参数组 | 形状与数量 |
| --- | --- |
| 字符与位置嵌入 | 4×16 + 16×16 = 320 |
| Q/K/V与注意力输出投影 | 四组16×16权重及16偏置 = 1088 |
| 前馈层 | 32×16+32、16×32+16 = 1072 |
| 三个LayerNorm | 各16缩放及16平移 = 96 |
| 输出分类层 | 4×16+4 = 68 |

合计 **2644个参数**。矩阵展平成行优先数组，权重按 `[输出][输入]` 存放。固定缓存覆盖最大上下文，无动态分配、模型文件或图片输出；所有输入/缓存由调用方拥有，相关函数注释说明长度和不重叠要求。没有 dropout、旋转位置编码、KV 缓存或多层堆叠。

## 2. 从单头手算到双头注意力

每个头计算：

```text
score[t,s] = dot(Q[t], K[s]) / sqrt(d_head)
A[t,:]     = softmax(score[t,:])，仅允许s<=t
C[t]       = sum_s A[t,s] V[s]
```

Q 表示当前位置的查询，K 用于匹配，V 是要汇聚的内容；它们都由输入的不同可学习线性变换产生。两头分别处理各自8维切片，拼接后的16维结果再做输出投影。缩放按每头维度8计算，不能误用整个模型维度16。

入口先展示一个可手算的单头例子：令Q=K=0，V三行每个分量分别为1、3、5，允许位置的分数相等：

```text
A = [1    0    0  ]       C = [1]
    [1/2  1/2  0  ]           [2]
    [1/3  1/3  1/3]           [3]
```

训练后展示 `abac acbc ` 的两头矩阵。行是查询，列是输入键位置；包括当前字符在内的每行有效权重和为1，未来列严格为0。打印四舍五入后行和可能略有偏差。不同头可能关注不同位置，但注意力权重不能单独证明语义理解或作为完整因果解释。

## 3. 因果掩码、位置与归一化

模型读第t个字符时可使用位置0～t，因为该行预测第t+1个字符。未来位置必须在 softmax 归一化**之前**排除；本例直接只遍历 `s<=t`，提前清零所有未来权重。先对全行归一化再把未来项清零，会让未来分数影响分母，产生泄漏。

LayerNorm 对每个位置的16个特征单独计算均值、总体方差，使用epsilon=1e-5，再施加可学习gamma/beta。它不在时间轴上归一化，因此不会从未来位置读取统计量；三组gamma初始为1，beta为0。

位置向量是可学习的绝对位置表示，每个上下文块从位置0开始。它帮助区分不同位置上的同一字符；本例没有演示移除位置表示后的完整训练对照，保留为练习。

因果验证覆盖两个条件：改变位置5之后的全部输入，前五个位置的预测逐值保持不变；将序列截短成同样的五字符前缀，结果也保持不变。单独注意力反向测试还验证，仅最早输出有导数时，未来Q/K/V没有导数。

## 4. 手写反向传播的要点

损失为按预测字符平均的稳定交叉熵，输出梯度为 `(p-one_hot(target))/T`。沿网络倒序传播，所有共享参数对各位置的贡献需要累加。

注意力反向先从C得到：

```text
dV[s] += A[t,s] dC[t]
dA[t,s] = dot(dC[t], V[s])
dscore[t,s] = A[t,s] (dA[t,s] - sum_j A[t,j]dA[t,j])
dQ[t] += dscore[t,s] K[s] / sqrt(d_head)
dK[s] += dscore[t,s] Q[t] / sqrt(d_head)
```

仅遍历允许位置，掩码边不会获得梯度。代码把缩放合并进ds，再同时用于Q和K导数。

LayerNorm反向需要包含均值与方差对输入的影响。令 `v=dy⊙gamma`，标准化值为hat，逆标准差为inv：

```text
dx = inv * (v - mean(v) - hat * mean(v⊙hat))
dgamma += dy⊙hat
dbeta  += dy
```

GELU采用标准正态CDF的erf形式，`GELU(x)=xΦ(x)`，导数为 `Φ(x)+xφ(x)`。前向和反向使用同一版本，没有混用tanh近似。

两个残差在反向都拆成直接路径和分支路径，并把导数相加；LN1输入收到Q、K、V三条投影分支的导数总和。最后的dx分别累加到字符嵌入和对应位置向量。不能只沿注意力或前馈支路回传，否则残差参数梯度会错误。

## 5. 训练、分组与生成

先用单条 `abcabcabc` 周期文本训练150轮，要求全部下一字符拟合正确。这一步训练与检查使用同一条数据，仅验证计算和微型拟合，不能报告为泛化结果。

正式实验复用阶段5的完整语料分组：训练8条、验证2条、测试2条，每条30字符。先确定分组，再把每条的29个预测对切成16步和13步两块，得到16/4/4个块。尾块保留，预测对不重叠，任何输入/目标都不跨字符串或数据分组边界。词汇及局部模式共享，测试只衡量同分布的新排列。

初始化种子42，Adam学习率0.003，全局梯度裁剪阈值1，完整全批量训练250轮。不同长度块的梯度先乘回各自字符数，再除以总字符数；验证指标也按字符加权。每轮仅根据验证CE保存最佳参数，最后一次性评估测试集，并对照从训练集统计的加一平滑bigram基线。

Apple Clang 17 固定实验结果：

| 模型/实验 | CE | 准确率 |
| --- | --- | --- |
| 单条周期拟合 | 0.00365 | 100% |
| Transformer独立测试 | 0.41237 | 79.31% |
| bigram独立测试 | 0.75419 | 60.34% |

模型保留第50轮，验证CE=0.39055；第250轮训练CE降到0.11971，验证CE升到1.06561，展示了过拟合。固定结果用于实现回归验证，不代表普遍语言能力。它与阶段5 RNN的上下文/训练配置不同，不应仅据数字排名网络优劣。

生成从一个a开始，每步选择最高概率字符作为新输入；超过16字符时只保留最近16字符，位置编号重新从0开始，重算全部上下文，不使用KV缓存。训练/评估用真实字符，生成读自己的输出，错误会累积。生成时标签只作占位，缓存loss无评估意义；应观察输出并结合独立测试结果判断。

## 6. 已验证内容与练习

- 全部2644个参数通过三位置展开的中心差分，包括重复字符嵌入、位置表示、注意力、三个LayerNorm、GELU及残差分支。
- 独立检查Q/K/V的144个输入导数，以及LayerNorm输入/gamma/beta的48个导数；完整模型梯度检查并不能替代理解这些局部公式。
- 验证单头手算、权重行和、未来权重为零、前向/反向因果性、常量特征归一化、最大上下文前向与反向、单字符预测块、非法字符及容量拒绝、裁剪和非有限更新失败不部分修改。
- 微型拟合、独立语料评估、日志双输出/追加行为由运行验证覆盖。

练习时先移除位置表示并重新训练；再修改上下文长度或头数，同时检查维度可整除、位置数组与注意力缓存。比较配置使用验证集，保持测试集不参与选择；之后可研究KV缓存或多层结构。主线阶段8是回看已有DQN贪吃蛇，把网络结构与强化学习训练方法联系起来。
