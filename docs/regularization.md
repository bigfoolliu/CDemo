# 阶段 10.2：神经网络正则化

源码：`src/ml/21_regularization.c`。运行 `make regularization` 对比不同 L2 系数，`make test-regularization` 验证解析梯度和数据边界，`make sanitize-regularization` 运行地址与未定义行为消毒器。示例用纯 C 和 `<math.h>`，不依赖机器学习框架，也不写入日志或图片。

## 为什么需要正则化

模型参数很多、训练样本很少时，网络可能把训练集中的偶然模式也学进去。训练损失会继续下降，但新样本上的验证损失可能反而升高。L2 正则在优化目标中惩罚较大的权重，限制网络使用极端参数拟合细节。

本例用 `2→24→1` 的 tanh MLP 学习二维圆形分类。每次实验只有 24 条训练数据，每条训练标签以 20% 概率翻转；验证和测试数据独立生成且不加噪声。较宽的网络有足够能力拟合少量训练异常，便于观察训练与验证表现的差距。实验重复三个随机种子，降低单次初始化和采样偶然性的影响。

## 数据损失与优化目标

二元交叉熵先对训练样本取平均，再加权重惩罚：

```text
J(W, b) = mean_i BCE(logit_i, y_i) + lambda/2 * sum_j(W_j * W_j)
```

`W` 表示两层线性变换的权重，`b` 表示偏置。偏置不参与惩罚。数据损失度量预测和标签的差异；L2 项是优化目标中额外的约束。对应梯度为：

```text
dJ/dW = d(data_loss)/dW + lambda * W
dJ/db = d(data_loss)/db
```

前向使用 `tanh` 隐藏层和 sigmoid 输出。二元交叉熵直接由 logit 稳定计算，不先对概率取对数。反向传播对输出误差 `p-y` 求导，然后依次通过输出层、`tanh` 和隐藏层。每轮先累计整批梯度，再一次性更新，优化器为全批量 SGD。

## 实验如何选参

程序测试 `lambda = 0、0.00003、0.0001、0.001、0.003、0.01`。每个候选使用相同训练集和相同初始参数，经过相同轮数训练。终端分别显示：

- `train_BCE`：训练集上的纯数据损失，不含正则项。
- `train_objective`：训练数据损失加 L2 项，是 SGD 实际优化的量。
- `val_BCE` 和 `val_accuracy`：选正则强度使用的验证指标。
- `||W||²`：两层权重平方和，不包含偏置。

程序仅按验证 BCE 选出一个系数，然后对对应模型评估一次独立测试集；测试结果不参与候选选择。三个种子结果还会报告均值。观察时注意：正则通常压低权重范数并提高训练损失，但测试表现不保证每次变好。过强正则会令模型欠拟合；在某个种子上选出 `lambda=0` 也属于有效结果。

## 验证和练习

测试对全部 49 个参数执行中心差分梯度检查，并验证 L2 梯度没有加到隐藏层偏置和输出偏置上。无正则时目标应等于数据损失；非法系数、非有限值和错误数据尺寸会被拒绝。

练习：将训练样本数改为 48，观察验证差距是否收窄；改变标签翻转比例，记录验证选中的系数；将惩罚扩展到偏置，再比较结果；把完整训练轮数替换为早停，并确保早停轮次只由验证集选择。不要因为某次测试分数更高就不断改候选范围，测试集只用于最终报告。
