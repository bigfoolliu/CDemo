# C 语言粒子喷泉

这是在二维像素引擎上增加的独立演示：小粒子从底部喷出，受重力影响下降，随着寿命减少逐渐变暗。没有图片素材、透明混合、拖尾或碰撞系统，便于观察基础原理。模拟和绘制是纯 C，SDL2 只提供窗口、输入、计时和显示。

## 运行和调试

窗口需要 SDL2 与 pkg-config，与原二维演示共用依赖。macOS 缺少依赖时可运行 `brew install sdl2 pkg-config`。

```sh
make particles                         # 构建并打开粒子窗口
make particles-build                   # 只构建
make particles-debug                   # 构建 -O0 -g3 调试版本
make compile-commands-graphics         # 更新包含 SDL 参数的代码提示
make test-particles                    # 纯 C 测试，不需要 SDL
make sanitize-particles                # 地址和未定义行为检查
make test-particles-window             # SDL dummy 驱动测试，需要 SDL
./build/graphics/particles_demo --frames 120  # 显示 120 帧后退出
```

默认 `make test` 和 `make lint` 包含粒子核心，不打开窗口、不引入 SDL。窗口源码的严格警告由 `particles-build` 检查。VS Code 选择 `C: 粒子喷泉演示` 后按 F5，启动任务自动更新编译数据库并构建。

| 操作 | 行为 |
| --- | --- |
| Space | 暂停/继续，清除积累时间 |
| N | 暂停时推进一次 1/60 秒模拟 |
| R | 清空粒子并恢复随机种子 42，保留暂停状态 |
| Esc / 关闭窗口 | 释放资源并退出 |

自动重复按键被忽略。窗口为 640×480，逻辑画布为 320×240，采用最近邻放大。标题显示存活数量和运行状态。

## 1. 从结构体到对象池

`particles.h` 中的 `Particle` 保存位置、速度、初始寿命和剩余寿命。坐标原点在左上角，x 向右、y 向下；位置单位为像素，速度单位为像素/秒。

`ParticleSystem` 自己拥有 256 个槽位和一个 `uint32_t` 随机状态。`remaining == 0` 表示空闲，每步先回收旧粒子，再扫描空槽发射最多两个粒子。满池时跳过发射，不覆盖存活粒子，也不推进随机状态。核心无需动态分配，扫描复杂度为 O(容量)。SDL 自身仍会分配窗口资源。

默认发射参数：

| 参数 | 值 |
| --- | --- |
| 发射位置 | `(160, 210)` |
| 水平速度 | `[-35, 35)` |
| 初始竖直速度 | `[-110, -70)`，负值向上 |
| 重力加速度 | `+90` 像素/秒² |
| 寿命 | 90～150 步，即 1.5～2.5 秒 |
| 发射频率 | 每步 2 个，每模拟秒最多 120 个 |

独立的线性同余随机流用于视觉教学；相同种子和步数产生相同序列，不受其他示例调用 `rand` 影响。它不适合安全用途。

## 2. 重力、位置和寿命

`particles_step` 使用固定 `dt = 1.0 / 60`，按半隐式欧拉方法更新：

```c
vy += 90 * dt;
x += vx * dt;
y += vy * dt;
--remaining;
```

先更新速度，再用新速度更新位置。负竖直速度逐渐趋近零，随后变正，形成上升再下落的轨迹。剩余寿命归零或位置离开 `[0,320) × [0,240)` 时回收。新粒子在本步末尾出生，下一步才开始运动，出生时保留完整寿命。

## 3. 模拟时间与显示帧分离

默认目标绘制帧率为 **60 FPS**，即每帧约 16.67 毫秒。主循环在一帧处理结束后调用 `SDL_Delay` 补足剩余时间，主动限速；由于延时精度、绘制耗时和系统调度影响，实际帧率不保证精确为 60 FPS。

粒子模拟采用 **每秒 60 次更新**的固定步长，每次推进 `1/60` 秒。当前实现用 `particles.h` 中的 `PARTICLE_HZ = 60` 同时设置模拟频率与绘制限速目标，但模拟更新和绘制仍是两个独立步骤。暂停时继续处理事件和绘制，暂停状态下按 N 只推进一次模拟更新。

`particles_demo.c` 的 `advance_time` 累积墙钟秒数，每满 1/60 秒调用一次更新，剩余时间留给下一帧。一次显示可能没有更新，也可能更新多次；发射速度和寿命由模拟步数决定。

单帧时间最多计入 0.1 秒，避免断点或系统挂起后大量补算。暂停不积累时间；恢复和重置丢弃当前帧增量。这里主动放弃过长停顿的时间，因此演示不承诺与真实时间严格同步，也没有绘制插值。

## 4. 在像素数组上绘制

`particles_draw` 将坐标用 `floor` 转为整数，画一个逻辑尺寸 2×2 的填充矩形。初始颜色是 `(255, green, 60)`，其中 green 在 180～230 之间；各通道乘以 `remaining / lifetime` 后逐渐变暗。颜色保持不透明，重叠粒子按数组顺序覆盖。

每帧清空背景，避免留下旧位置。靠近右边或下边的方块由现有绘图核心裁切。共享的 `graphics_sdl.c` 按 SDL 返回的行跨度复制画布，再将整张纹理显示到窗口。

## 阅读顺序与练习

按 `particles.h → particles.c → particles_demo.c → graphics_sdl.c` 阅读。建议在 `particles_step` 的速度更新和空槽写入处设断点，暂停后按 N 观察字段；在 `advance_time` 中观察不足一步的余量。

练习：将重力设为零比较直线轨迹；改变发射速度和寿命；减小池容量观察发射受限；改变粒子尺寸。修改后运行核心测试与消毒器。

测试验证可重复性、运动数值、出生/寿命、四边回收、满池和槽位复用、亮度及裁切；SDL dummy 测试验证控制状态和有界主循环。真实窗口的外观与键盘体验仍需运行演示观察。
