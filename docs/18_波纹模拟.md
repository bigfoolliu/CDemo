# 二维波纹模拟（2D ripple simulation）

本示例用纯 C 的二维数组模拟水面高度，用既有软件画布和 SDL2 显示。可以点击产生波峰或波谷，观察传播、叠加、边界反射和阻尼衰减。它展示离散波动方程的基本原理，不求解完整流体方程，也不包含真实水面折射。

## 1. 运行和操作

窗口使用 [二维图形教程](10_二维图形引擎.md) 中的 SDL2 与 pkg-config 环境。在仓库根目录运行：

```sh
make ripple                    # 构建并启动
make ripple-build              # 只构建窗口程序
make ripple-debug              # -O0 -g3 调试版本
make compile-commands-graphics # 包含 SDL 的代码提示
./build/graphics/ripple_demo --frames 120 # 显示 120 帧后退出
```

| 操作 | 效果 |
| --- | --- |
| 左键 / 右键点击 | 添加正 / 负圆形位移，暂停时也可添加 |
| Space | 暂停 / 继续，不累积暂停时间 |
| N | 暂停时前进一步，运行时忽略 |
| R | 恢复中央初始波纹，步数归零 |
| C | 清空成平静水面，步数归零 |
| S | 保存本帧 BMP 到 `exports/ripple-<时间>-<序号>.bmp` |
| Esc / 关闭窗口 | 退出并清理资源 |

R/C 保留暂停状态。最外圈固定不动，点击该圈忽略；靠边的扰动圆裁切到内部网格。每次按下只添加一个扰动，按住鼠标不会自动连续滴水。截图独占创建，不覆盖已有图片，写入失败在终端报错后继续运行；图片是 320×240 的逻辑画布。

## 2. 用高度场表示水面

网格为 **160×120**，每格显示为 2×2 个逻辑像素；画布 320×240，默认窗口 640×480。左上角为原点，x 向右、y 向下。高度是示意值而非以米计量：零为平静水面，正数为凸起，负数为凹陷。

`RippleWorld.height[2][120][160]` 保存两个时刻。`current` 指向当前层，另一层是上一时刻。两层高度差近似表达速度；不需要单独的速度数组。状态由调用者持有，无动态分配；两层数组约 150 KiB，因此窗口使用静态对象，避免大栈对象。

先调用 `ripple_reset` 初始化，再通过公开接口操作。可以只读数组观察变化，不能直接写入 NaN、无穷大或破坏边界。接口检查地址、层编号和扰动参数，不对每次调用的全部数组作外部损坏检查。

## 3. 波如何传播

连续波动方程用高度的空间二阶导数描述附近水面的牵引。网格上用四邻居的离散拉普拉斯近似：

```text
laplacian = left + right + up + down - 4 * current
velocity  = current - previous
next      = 2 * current - previous + r * laplacian - d * velocity
```

代码中 `r=0.20`，`d=0.01`。中心比邻居高时，拉普拉斯为负，它会向下运动；邻居又受到中心牵引向上运动，于是形成向外扩散的波。阻尼项逐步减小运动，而不是每步直接删除高度。

`r` 对应 `(波速 × 时间步 / 网格间距)^2`，`d` 对应阻尼率乘以时间步。这些是固定的无量纲系数。对于此二维四邻居显式差分形式，稳定系数须满足 `0 ≤ d < 2`、`0 ≤ r ≤ (2-d)/4`；本例参数留有余量。不要只增大 r 来追求更快传播，否则数值可能爆炸。网格方向会影响离散波的形状，它不是完全各向同性的连续水面。

更新时，空间邻居全部读取当前层。旧层只读取同一格的 previous，随后可用 next 覆盖；遍历结束交换层编号。不能原地覆盖当前层，否则后面的格子会读取已经更新的邻居，造成方向偏差。

最外圈在两个缓冲区中始终为零，相当于固定边界，会反射波；它不是吸收边界。阻尼使反射逐渐减弱。步数使用 `uint64_t`，到达最大值后饱和，不回绕。

## 4. 扰动、限幅与明暗

点击生成半径 6 格、幅度 ±8 的余弦包络：中心位移最大，边缘平滑降为零。同时给当前层和上一层加相同位移，在未触发限幅时保持原有速度，即添加一个初始位移而不是速度冲击。

为防止反复点击堆积极大数值，扰动和更新将高度限制到 **±64**。这是教学程序的保护措施；达到限幅后不再保持线性叠加或精确的波动方程行为。限幅前，可以在不同位置点击，观察两组波相互穿过与干涉。

绘制使用左右、上下的高度差近似坡度，再结合少量高度项得到明暗，限制到 [0,1] 后映射成蓝色 RGB。坡度让环形波纹更明显；颜色不是高度的精确量尺，也没有透明度、法线归一化、抗锯齿或物理光照。

## 5. 帧率与模拟时间

默认目标显示 **60 FPS**，模拟使用固定 **1/60 秒**步长。计时器把真实时间加入 accumulator，够一步就模拟一步，剩余时间留给下一帧。显示次数和模拟步数分别统计，窗口标题显示模拟步数。

单帧最多接收 0.1 秒、追赶六步，长断点或窗口卡顿的多余时间会丢弃，避免恢复后长时间阻塞。暂停不积累时间，切换暂停或 R/C 会清除余量及本帧耗时。实际显示帧率受系统调度、绘制和截图影响，不保证严格 60 FPS。

## 6. 文件、验证与调试

| 文件 | 职责 |
| --- | --- |
| `src/graphics/ripple.h/c` | 高度场、扰动、差分更新和着色，完全不依赖 SDL |
| `src/graphics/ripple_demo.c` | 输入、暂停、固定时间步和 BMP 请求 |
| `tests/ripple_test.c` | 传播、对称、衰减、边界、限幅与失败行为 |
| `tests/ripple_window_test.c` | 时间累积、点击映射、控制与截图主循环 |

```sh
make test-ripple          # 纯 C 数值与绘制断言
make sanitize-ripple      # 地址与未定义行为消毒器
make test-ripple-window   # 需 SDL2，dummy 视频驱动，无实际窗口
make test
make lint
```

无效扰动不改变水面，窗口外点击忽略；输入有限数和幅度范围均有断言。测试还验证单格扰动首次只传播到四邻居、长期衰减、正负对称及零边界。截图测试使用临时目录，保留用户图片。

VS Code 选择 `C: 波纹模拟` 按 F5。建议暂停后，在 `ripple_step` 中设置 `x == 80 && y == 60` 条件断点，按 N 观察一次传播。进一步练习：比较不同阻尼；用第三个缓冲区改写更新并对照结果；设计吸收边界；增加自动雨滴；将坡度用于背景纹理偏移。这些扩展当前尚未实现。
