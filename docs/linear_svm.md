# 线性支持向量机：hinge 损失与间隔

本案例对应 [学习计划阶段 9.5](deep_learning_plan.md)，源码为 `src/ml/19_linear_svm.c`。它在固定种子的二维合成数据上，用纯 C 实现软间隔线性 SVM，并在相同训练数据上训练逻辑回归作对照。

运行 `./build/ml/19_linear_svm` 查看 SVM 参数、hinge 数据损失、训练/测试错误和几何间隔。运行 `make linear-svm` 还会把两种分类区域和边界导出到 `exports/`：左图为 SVM，实线是决策边界，灰线是两侧间隔；右图为逻辑回归。训练点用实心圆表示，测试点用白色外圈标出。BMP 使用独占创建，不覆盖已有图像。

## 优化目标

线性模型对输入 (x) 输出分数 (f(x)=w^Tx+b)。标签使用 (y\in\{-1,+1\})，预测符号由分数决定。间隔为 (yf(x))：若至少为 1，样本在正确一侧且位于间隔边界之外；若小于 1，则产生 hinge 损失：

```text
L_hinge = max(0, 1 - y f(x))
J(w,b) = mean(L_hinge) + (lambda / 2) * ||w||²
```

正则项只约束权重 `w`，偏置 `b` 不惩罚。对违反间隔的样本，权重数据梯度为 `-y*x`，偏置梯度为 `-y`；满足间隔的样本对数据梯度贡献为零。案例将这组次梯度与 `lambda*w` 合并，按小批次更新参数。hinge 在间隔恰为 1 的位置不可微，程序采用零数据梯度这一合法次梯度。

决策边界是 (f(x)=0)，SVM 两侧间隔线是 (f(x)=\pm1)。对可分数据，两条间隔线之间的几何宽度为 (2/||w||)，从边界到任一侧为 (1/||w||)。增加正则化会偏好较小的权重范数，但可能增加违反间隔的样本。

## 对照与练习

合成标签由线性边界和少量扰动产生，并包含固定位置的标签翻转，因而不是完全可分。SVM 与逻辑回归共用训练/测试划分和 L2 系数；测试集只用于最后报告，不能用它调参。两者损失的定义不同，比较时重点观察分类错误、边界与 SVM 间隔，不要把损失值直接当成同一尺度。

可以改动 `REGULARIZATION`，观察权重范数、间隔及测试错误的变化；再移除标签翻转，比较硬分类边界与软间隔的影响。进一步尝试中心差分检查 `margin < 1` 区域的次梯度，并单独检查 `margin > 1` 时损失梯度为零。
