# 随机森林：自助采样与随机特征

本案例对应 [学习计划阶段 9.3](deep_learning_plan.md)。源码 `src/ml/17_random_forest.c` 使用固定容量数组手写一组二分类树，不依赖机器学习框架。

```sh
make random-forest
make sanitize-random-forest
./build/ml/17_random_forest
```

案例使用 64 个二维训练点和 64 个独立坐标测试点，目标是圆形区域内为正类；训练标签含少量由固定索引规则产生的噪声，测试标签保持干净。这样可以观察单棵较深树对噪声的拟合，以及森林投票的波动。同一数据上对比全量训练的单棵 CART 与 31 棵树的森林，并以三个固定种子重复实验。程序同时显示多数类基线、训练错误、测试错误和袋外错误。

## 一棵森林树如何产生

每棵树从 64 条训练样本中有放回抽取 64 次。某条原始样本可能在 bootstrap 数据中重复，也可能一次都没抽到；后者标记为袋外样本。训练每个节点时，从两个特征中随机选一个，只在该特征上枚举相邻不同值的中点，按基尼增益选切分。树最大深度为 6，叶节点用多数类投票，叶内票数相同时选 0。随机状态由传入种子推进，因此相同种子可重复整个森林。

森林预测时，每棵树投一票，票数较多的类别获胜；总票平局取类别 0。输出的正类投票比例是树的投票占比，不是经过校准的概率。

## 袋外评估和测试集

每棵树只对没进入自己 bootstrap 样本的训练点投袋外票。汇总多棵树的袋外票后得到 OOB 错误数和覆盖样本数；如果某个点没有任何 OOB 票，就不计入该次 OOB 准确率。OOB 让训练集内部也能获得评估信号，但这些样本仍参与了森林的其他树训练，所以案例另外保留独立测试集，并报告多个种子的测试表现。

测试坐标来自相同的象限规则，但相对训练网格平移半格，不与训练坐标重合。这验证了简单合成分布上的插值行为，不代表模型能泛化到真实数据。多个种子的均值展示随机波动；不假定森林在这个容易由一棵树表达的规则上一定优于单树。

## 读代码与练习

建议依次观察 `member_train` 的 bootstrap 与袋内标记、`build_tree_node` 的随机特征选择、`find_candidate` 的基尼增益计算、`forest_predict` 的投票和 `oob_evaluate` 的覆盖统计。

练习：把 `TREE_COUNT` 改成 1、5、31，观察投票波动和运行时间；改变树深度，比较训练错误、测试错误与袋外错误；将随机特征数从 1 改成 2，思考两特征小数据上各棵树会变得多相似。随机数发生器仅用于复现实验，不适合安全用途。
