# 二维决策树：从基尼增益到决策边界

本案例对应 [学习计划阶段 9.2](deep_learning_plan.md)。源码为 `src/ml/16_decision_tree.c`：用纯 C 训练二分类 CART 风格决策树，复用项目的画布与 BMP 导出，不需要 SDL 或机器学习框架。

```sh
./build/ml/16_decision_tree  # 构建后直接运行：仅打印树和误差
make decision-tree           # 构建、运行并导出决策边界 BMP
make test-decision-tree      # 手算、停止条件与失败路径测试
make sanitize-decision-tree  # 地址和未定义行为检查
```

输出图片在 `exports/`，文件名带时间与序号并独占创建，不覆盖已有图片。默认 `make ml` 和 `make test` 不生成图片。

在 VS Code 中选择 `C: ml/16_decision_tree.c` 后按 F5，会先构建调试版再带 `--export` 运行；可在 `find_split` 中观察候选阈值与基尼增益，在 `build_node` 中观察递归生成的节点。

## 1. 数据与树的目标

训练集是 4×4 的坐标网格，`x0>0` 且 `x1>0` 时标签为 1，否则为 0；独立测试集用网格中未出现的 8 个坐标。树的每个内部节点只检查一个条件：`x[feature] <= threshold` 走左边，其余走右边。叶节点取其中的多数类；票数相同取类别 0。

根节点有 4 个正类、12 个负类，因此基尼不纯度为 `2×(4/16)×(12/16)=0.375`。若在 `x0=0` 切分，左边 8 个全为负类，不纯度 0；右边正负各 4 个，不纯度 0.5。加权子节点不纯度为 `8/16×0 + 8/16×0.5 = 0.25`，**基尼增益为 0.125**。程序对两个特征排序，只枚举相邻不同值的中点，计算全部合法候选的增益。

## 2. 从树桩到深度 2

树桩只允许一次切分：右半边正负票数相同，仍预测 0。它的训练错误数为 4/16，测试错误数为 2/8。深度 2 的树在右半边继续按 `x1=0` 切分，两组错误数都变成 0。这是固定、简单规则上的结果，不能证明模型对其他数据有相同精度。

同增益时按特征 `x0`、`x1` 的顺序和候选阈值升序选择，输入不变则生成同一棵树。图片左半幅显示树桩，右半幅显示深度 2 的树：蓝色区域预测类别 0，橙色区域预测类别 1，圆点是训练样本。背景是预测，不代表那些未采样位置的真实准确率。

## 3. 停止与失败行为

- `max_depth=0` 只产生根叶节点；纯节点、样本不足以满足两个 `min_leaf` 子节点、重复坐标没有合法阈值，或没有正增益时也停止。阈值左侧使用 `<=`，避免把相同数值的样本拆开。
- 输入限于最多 64 个坐标均在 `[-1,1]` 的有限二维样本，标签只能是 0 或 1。节点使用固定容量数组，不分配动态内存。训练先构造临时树，失败时不替换旧树；预测失败不修改输出。
- 贪心切分只看当前一步增益，不能保证全局最优；例如完全对称的 XOR 数据可能在根节点没有正增益，本实现会停为单叶。测试覆盖这一类重复值、纯节点、深度、最小叶规模、平局和非法输入。

练习：改动 `min_leaf` 和 `max_depth`，比较训练与测试错误数；为数据加入噪声，观察深树是否更容易记住异常点。完成后可进入 [随机森林阶段](deep_learning_plan.md)，学习为什么组合多棵不同的树。
