# 康威生命游戏（Conway's Game of Life）：用 C 学习细胞自动机（cellular automaton）

生命游戏没有玩家胜负：每个细胞只根据周围八个细胞决定下一代状态，简单规则可以产生稳定结构、周期振荡和移动图案。本示例重点展示二维数组、邻域遍历、同步更新与双缓冲；规则核心使用纯 C，SDL2 提供窗口和输入。

## 1. 运行与操作

窗口沿用现有图形模块的 SDL2 与 pkg-config 依赖，macOS 缺少依赖时可使用 `brew install sdl2 pkg-config`。SDL 是第三方库，核心规则不依赖 SDL。

```sh
make life                         # 构建并打开窗口
make life-build                   # 只构建窗口程序
make life-debug                   # 构建 -O0 -g3 调试程序
make compile-commands-graphics    # 更新含 SDL 头文件路径的代码提示
make test-life                    # 纯 C 规则与像素断言，无需 SDL
make sanitize-life                # 地址与未定义行为检查，无需 SDL
make test-life-window             # SDL dummy 驱动测试控制，不显示窗口
./build/graphics/life_demo --frames 120  # 显示 120 帧后自动退出
```

默认加载居中的滑翔机并运行。窗口标题显示图案、代数、存活数量和暂停状态。80×60 网格覆盖 320×240 逻辑画布，每格 4×4 像素；在 640×480 窗口中每格占 8×8 像素。存活细胞画成绿色方块，格间保留深色细线。

| 操作 | 行为 |
| --- | --- |
| Space | 暂停/继续 |
| N | 暂停时推进一代；运行时忽略 |
| 1 | 加载滑翔机 |
| 2 | 加载闪烁器 |
| 3 | 加载约 25% 存活率的随机图案 |
| R | 恢复最近选择的预设，随机预设使用种子 42 重现 |
| C | 清空网格并进入暂停 |
| 鼠标左键 | 暂停时切换一个细胞，运行时忽略 |
| Esc / 关闭窗口 | 释放资源并退出 |

切换预设和重置将代数归零，保留暂停状态；鼠标编辑也将代数归零并显示 custom，R 仍恢复最近选择的预设。清空不改变最近选择的预设。自动重复按键被忽略，不支持拖动连续绘制。点击格间细线仍归属于对应格子。

## 2. B3/S23 演化规则

每格有“存活”和“死亡”两种状态。统计上、下、左、右和四个对角线共八个邻居，排除自身。

| 当前状态 | 存活邻居数量 | 下一代 |
| --- | --- | --- |
| 死亡 | 恰好 3 个 | 出生 |
| 存活 | 2 或 3 个 | 保持存活 |
| 任意 | 其他情况 | 死亡 |

“B3”表示三个邻居时出生，“S23”表示两个或三个邻居时存活。代码可合并为：

```c
next_alive = neighbors == 3 || (alive && neighbors == 2);
```

坐标原点位于左上角，x 表示列、y 表示行。有效范围为 `[0,80) × [0,60)`；网格外始终视为死亡，左右或上下不会相连。滑翔机到达边界后可能改变形态或消失，这符合本例的有限网格规则。

## 3. 为什么需要双缓冲

不能一边读取邻居，一边覆盖当前网格：后面的细胞会读到已经更新的邻居，同一代的结果就取决于扫描顺序。

`LifeWorld` 保存两个 `bool` 数组和一个 `current` 索引。每一代：

1. 从 `cells[current]` 读取所有旧状态。
2. 将所有格子的结果写入 `cells[1 - current]`。
3. 全部计算完成后切换 `current`，代数加一。

每格包括死亡结果都被覆盖，所以目标数组无需提前清空。两个数组复用，没有逐代动态内存分配或复制整张网格；代数是 `uint64_t` 无符号计数，到达其上限后按 C 规则回绕。

接口中的 `world` 地址必须有效且已初始化，`current` 只能为 0 或 1。`life_get` 对越界坐标返回死亡，`life_toggle` 对越界坐标返回 false 且不修改世界。切换细胞只修改当前数组，下一次演化会完整覆盖另一张数组。

## 4. 经典图案与随机初始状态

- **滑翔机**：五个细胞组成，四代后形状相同并向右下移动一格。
- **闪烁器**：三个细胞在横向与纵向之间交替，两代恢复原状。
- **随机图案**：独立的 `uint32_t` 线性同余随机流，每格依据高两位决定是否存活。固定种子 42 使重置可以重现，不使用全局 `rand`，也不适用于安全用途。

可先暂停并单步观察闪烁器，再清空用鼠标画 2×2 方块：方块中每格恰好有三个邻居，因此不会变化。只有一个细胞时，下一代会因没有邻居而死亡。

## 5. 绘制帧率与演化频率

默认目标绘制帧率为 **60 FPS**，每帧约 16.67 毫秒；演化频率为 **每秒 10 代**，固定步长为 0.1 秒。主循环累计实际经过的秒数，每满一步才调用 `life_step`，不足一步的时间留给下一帧。因而多数显示帧不会演化，只重复显示当前世界。

一帧最多计入 0.1 秒，长停顿的多余时间会被丢弃。暂停不积累时间，恢复、重置和切换预设丢弃当前帧增量，避免立即跳代。按 N 直接推进一代，与时间累积器无关。

显示结束后通过 `SDL_Delay` 等待剩余帧时间，延时精度、绘制耗时和调度会影响实际 FPS。该频率是限速目标，不保证精确刷新，也不保证长停顿后的模拟与真实时间同步。

鼠标坐标依据当前窗口宽高按比例换算为网格坐标；SDL 事件与窗口尺寸使用相同坐标单位，不直接假定物理显示器像素密度。绘制只读取世界，先清屏再绘制，避免死亡格留下旧图像。

## 6. 阅读、调试与验证

建议按 `life.h → life.c → life_demo.c` 阅读。先理解 `life_get` 的边界判断，再看 `life_step` 的邻域循环和缓冲切换，最后看事件、时间累积和显示流程。源码提供中文函数契约及关键步骤注释。

VS Code 选择 `C: 康威生命游戏` 后按 F5。启动任务先生成图形编译数据库，再构建调试程序。可在 `neighbors` 累加、下一代写入和 `current` 切换处设断点，观察两张数组；窗口暂停只停止演化，调试器断点则暂停整个进程。

核心测试覆盖规则真值表、空世界、稳定方块、闪烁器、滑翔机、边界、随机可重复性、编辑与像素绘制，并接入默认 `make test` 和 `make lint`。SDL dummy 测试验证预设、鼠标映射、暂停单步、时间和自动退出。实际外观与键鼠体验需打开窗口观察。

练习：尝试其他稳定图案；把演化频率从 10 改为 5；增加一个预设；将边界改成首尾相连并补充测试。修改后运行核心测试与消毒器。本版没有无限网格、缩放拖动或图案文件导入导出。

## 7. 保存当前画面

按 S 将本帧画布保存为 `exports/` 内的 BMP，终端输出实际路径；文件自动命名，不覆盖已有图片。可先暂停再截图。导出为原始 320×240 像素，不包含窗口标题或显示放大。原理、接口及测试见 [BMP 图片导出](11_BMP图片导出.md)。
