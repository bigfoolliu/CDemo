# 用纯 C 理解残差网络 ResNet

本案例在 [阶段 11.1](deep_learning_plan.md) 实现一个小型图像分类网络。运行 `make resnet`，
对照普通 CNN 与 ResNet；运行 `make test-resnet` 检查反向传播，运行 `make sanitize-resnet`
检查内存和未定义行为。代码位于 `src/ml/22_resnet.c`，无需外部机器学习框架。

## 网络结构与张量

输入是 `8×8` 灰度图。stem 卷积把一个通道变成两个通道；残差块保持空间尺寸和通道数不变：

```text
普通 CNN：stem → Conv(3×3) → ReLU → Conv(3×3) → ReLU → 全局平均池化 → 分类层
ResNet：  stem ────────────────┐
                 Conv → ReLU → Conv → 加法 → ReLU → 全局平均池化 → 分类层
                              └──── 恒等捷径 ────┘
```

数组按 `[channel][row][column]` 连续存放。卷积使用步长 1 和零填充，因此主分支输出与
捷径的形状都是 `[2][8][8]`。两种网络使用完全相同的 105 个参数、训练数据、初始化和
训练轮数，唯一差别是块输出是否加上 stem 张量。

## 前向与反向传播

残差块的计算为 `y = ReLU(x + F(x))`，其中 `F` 是两层 3×3 卷积。普通 CNN 对应
`y = ReLU(F(x))`。反向传播先根据 ReLU 的掩码得到加法处的梯度；残差结构将它同时传给
主分支和恒等分支：`dL/dx = dL/dy + dL/dF · dF/dx`（仅在输出 ReLU 激活时）。这条直接
梯度通道是残差连接帮助深层网络优化的核心直觉。

代码先累积一整批样本的梯度，再执行一次全批量 SGD 更新；池化、卷积、偏置和分类层都
手工实现。案例用中心差分检查两种网络的每一个参数，以及一个输入像素的梯度，并单独
手算恒等路径的梯度。

注意：这是很小的合成线条任务，三次运行只能展示同参数量下的实验方法，不能证明 ResNet
