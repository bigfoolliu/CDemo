# C 转义字符、整数后缀与输出格式

本文整理 C 字符串和字符常量中的转义写法、整数常量后缀，以及 `puts`、`printf` 的常见用法。项目以 C23 为目标；编译器和 C 标准库对新特性的支持程度可能不同。

## 1. 什么是转义字符

反斜线 `\` 在字符常量和字符串字面量中开始一个转义序列。它让源码可以表示换行、引号、反斜线、控制字符或指定数值的字符。

```c
char newline = '\n';
char quote = '\'';
const char *message = "第一行\n第二行\n";
const char *path = "C:\\temp\\notes.txt";
```

字符常量用单引号，如 `'\n'`；字符串字面量用双引号，如 `"\n"`。`'\n'` 表示一个换行字符，`"\n"` 是包含换行和末尾字符串终止符的字符数组。

## 2. 常用标准转义序列

| 写法 | 含义 | 常见用途 |
| --- | --- | --- |
| `\'` | 单引号 | 在字符常量中表示 `'`，如 `char c = '\'';` |
| `\"` | 双引号 | 在字符串中表示 `"`，如 `"他说：\"你好\""` |
| `\?` | 问号 | 表示 `?`；过去常用于避免三字符组问题，现代代码通常直接写 `?`。 |
| `\\` | 反斜线 | 路径、正则表达式等文本中的 `\`。 |
| `\a` | 响铃字符 | 请求终端或设备发出提示音，是否可听取决于环境。 |
| `\b` | 退格 | 光标向左移动一格；不等于删除字符串中的字符。 |
| `\f` | 换页 | 传统打印控制字符，普通终端中较少使用。 |
| `\n` | 换行 | 输出下一行；文本文件的实际换行表示还可能受平台影响。 |
| `\r` | 回车 | 将光标移到当前行开头，常用于进度显示；与 `\n` 含义不同。 |
| `\t` | 水平制表符 | 输出一个水平 Tab；显示宽度由终端决定。 |
| `\v` | 垂直制表符 | 垂直方向的制表控制字符，日常较少使用。 |

终端控制字符的外观由终端决定。例如，`\b` 通常移动光标，但不保证会擦除光标左边的内容；响铃也可能被系统静音。

## 3. 数值转义与 Unicode 写法

### 八进制与十六进制

- `\ooo`：反斜线后接 1 到 3 个八进制数字（`0`～`7`）。例如 `\101` 的数值是八进制 `101`，在常见 ASCII/UTF-8 环境中对应 `A`。
- `\x...`：反斜线、字母 `x` 后接一个或多个十六进制数字。它会一直读取后续十六进制数字，直到遇到非十六进制字符。
- `\0` 是八进制转义，表示数值为零的空字符，常用于字符串结束符；字符串字面量本身也会自动附加一个结束用的 `\0`。

```c
char letter = '\x41';       /* 常见 ASCII 环境中是 'A' */
char digits[] = "\101";     /* 八进制 101，也是常见环境中的 'A' */
char text[] = "A\0B";       /* 含有内嵌空字符，普通字符串函数会在它处停止 */
```

十六进制转义会尽可能多地吞入后续数字，所以 `"\x41B"` 是一个数值为 `0x41B` 的转义，不是字符 `A` 后跟 `B`。需要分开时，可用相邻字符串字面量：

```c
const char *text = "\x41" "B"; /* 两段字符串在编译时连接，结果为 "AB" */
```

数值转义的值必须能由相应字符类型表示。不要假定任意机器都用 ASCII，也不要用数值转义表示 UTF-8 多字节字符，除非确实在处理字节协议。

### 通用字符名

`\u` 后接 4 位十六进制数，`\U` 后接 8 位十六进制数，用 Unicode 码点表达字符。例如 `"\u4E2D\u6587"` 表示“中文”两个码点。码点能否按预期显示，还取决于源码编码、编译器采用的执行字符编码和终端编码；本仓库源码使用 UTF-8 时，直接书写中文通常更容易阅读。

### 反斜线加物理换行

源码行末的反斜线紧接物理换行时，预处理会删除这两个字符，把两行拼成一行。它**不会**在运行时输出换行；输出换行请写 `\n`。长字符串通常用相邻字面量排版，避免意外把缩进空格拼进内容：

```c
printf("这是一段较长的文字，"
       "相邻字符串会在编译时连接。\n");
```

`\e` 常被某些编译器当作终端 Escape 字符，但它不是 ISO C23 的标准转义序列；依赖它会降低可移植性。需要终端颜色等控制码时，应明确标注平台或终端协议依赖。

## 4. puts 与 printf

### puts：输出一行字符串

`puts` 在 `<stdio.h>` 中声明，接收一个以 `\0` 结尾的字符串，将字符串写到标准输出 `stdout`，并自动追加一个换行符。成功时返回非负值，发生输出错误时返回 `EOF`。

```c
#include <stdio.h>

int main(void)
{
    puts("Hello, C!"); /* 输出 Hello, C!，然后换行 */
    return 0;
}
```

`puts` 不解析 `%d`、`%s` 等格式说明符，字符串中的 `%` 会原样输出。它适合输出固定文本；要插入变量或控制小数位数时使用 `printf`。若不希望自动换行，可用 `fputs(text, stdout)`。`puts` 的返回类型是 `int`：成功时返回非负值，发生输出错误时返回 `EOF`。

### printf 的格式说明符

`printf` 按格式字符串解释后续参数。常见结构是：

```text
%[标志][最小宽度][.精度][长度修饰符]转换说明符
```

格式说明符和实参类型必须匹配。可变参数函数不会自动检查这种匹配；类型不一致会导致未定义行为，结果可能错误，也可能造成更严重的问题。

| 格式 | 对应类型/用途 | 示例 |
| --- | --- | --- |
| `%d` | `int` 有符号十进制整数 | `printf("%d", -12);` |
| `%u` | `unsigned int` 无符号十进制整数 | `printf("%u", 12u);` |
| `%ld`、`%lld` | `long`、`long long` | `printf("%lld", big_number);` |
| `%zu` | `size_t`，常用于 `sizeof` 和数组元素个数 | `printf("%zu", sizeof value);` |
| `%f` | `double` 的定点小数形式 | `printf("%f", value);` |
| `%.1f` | `double`，小数点后显示 1 位 | `printf("%.1f", value);` |
| `%e`、`%g` | `double` 的科学计数法、紧凑格式 | `printf("%g", value);` |
| `%Lf` | `long double` | `printf("%Lf", long_value);` |
| `%c` | 经过整数提升后的字符值 | `printf("%c", 'A');` |
| `%s` | 指向以 `\0` 结束的字符数组的指针 | `printf("%s", name);` |
| `%p` | `void *` 指针 | `printf("%p", (void *)&value);` |
| `%x`、`%X`、`%o` | 无符号整数的十六进制或八进制表示 | `printf("%x", 255u);` |
| `%b` | C23 新增：无符号整数的二进制表示，标准库可能尚未支持 | `printf("%b", 10u);` 输出 `1010` |
| `%%` | 输出一个百分号，不消耗参数 | `printf("完成 50%%");` |

### 无符号整数与常量后缀

```c
#include <stdio.h>

int main(void)
{
    unsigned int bits = 5u;
    printf("bits=%u\n", bits);
    return 0;
}
```

`unsigned int` 是无符号整数类型，取值范围从 `0` 到 `UINT_MAX`；`bits` 只是变量名，类型并不会自动把数值解释成一组位。整数常量 `5` 默认类型为 `int`，后缀 `u`（也可写 `U`）明确表示无符号整数常量。这里的 `5u` 与变量的无符号类型相匹配；`unsigned int bits = 5;` 也合法，因为值 `5` 可以转换为 `unsigned int`。若将负数赋给无符号变量，结果会按模 `UINT_MAX + 1` 转换，不会保留负号。

格式符也要匹配：`%u` 对应 `unsigned int`，`%d` 对应 `int`。`u` 后缀只影响整数常量的类型，不是输出格式，也不会改变变量名的含义。较大的整数还可用 `ul`、`ull` 等后缀指定 `unsigned long`、`unsigned long long`，但应根据目标类型和取值范围选择。

`float` 作为 `printf` 的可变参数时会提升为 `double`，所以仍用 `%f`。`long double` 才用 `%Lf`。在 `printf` 中，`%f` 的 `l` 修饰符没有额外作用；不要把这条规则套到 `scanf`，`scanf` 的 `%f` 和 `%lf` 分别对应 `float *` 和 `double *`。

### 为什么 sizeof 要用 %zu

`sizeof` 的结果类型是 `size_t`，它表示对象或内存区域的大小。`size_t` 在不同平台上可能对应不同的无符号整数类型，因此应用 `%zu`：

```c
#include <stddef.h>

int values[] = {10, 20, 30};
size_t count = sizeof values / sizeof values[0];

printf("数组占用 %zu 字节，含有 %zu 个元素\n", sizeof values, count);
```

`%d` 要求对应参数是 `int`，不能用它打印 `size_t`。即使某台电脑上输出看起来正确，类型不匹配仍属于未定义行为。若输出固定宽度整数（例如 `uint32_t`），可使用 `<inttypes.h>` 中匹配类型的 `PRIu32` 等宏。

### 宽度、精度与常用标志

- 宽度是**最小字段宽度**，不足时补空格；不会截断较长的值。例如 `%5d` 至少占 5 列。
- 对 `%f`，精度表示小数点后的位数：`%.1f` 显示 1 位，`%.3f` 显示 3 位。它只影响显示，不会修改变量。
- 对 `%s`，精度是最多输出的字节数，不保证等于 UTF-8 字符数。对整数，精度通常表示最少数字位数。
- `-` 左对齐，`+` 显示正数符号，`0` 用零填充数字字段，`#` 对部分进制格式添加前缀或保留小数点。

```c
printf("[%8d]\n", 42);       /* 右对齐，字段至少 8 列 */
printf("[%-8s]\n", "C语言"); /* 左对齐；UTF-8 的终端列宽不一定等于字节数 */
printf("%08d\n", 42);        /* 数字前补零，输出 00000042 */
printf("%.1f\n", 12.36);     /* 输出 12.4；舍入后的显示值 */
printf("%.3g\n", 12345.0);   /* 约 3 位有效数字，可能使用科学计数法 */
```

## 5. 一个完整的小例子

```c
#include <stdio.h>

int main(void)
{
    int score = 95;
    double temperature = 21.678;
    const char *student = "小林";

    printf("姓名：%s\n分数：%d\n温度：%.1f °C\n", student, score, temperature);
    printf("进度：100%%\n");
    return 0;
}
```

运行时 `\n` 使输出分行，`%s` 对应字符串，`%d` 对应 `int`，`%.1f` 对应 `double` 并限制显示精度，`%%` 输出字面上的 `%`。不要把用户提供的文本直接作为格式字符串；使用 `printf("%s", text)` 或有明确格式的调用。

## 6. 初学者容易写错的地方

```c
size_t bytes = sizeof(int);
double ratio = 2.5;

printf("%d\n", bytes);       /* 错：%d 要求 int，bytes 是 size_t */
printf("%d\n", ratio);       /* 错：%d 要求 int，ratio 是 double */
printf("%f\n", ratio);       /* 对：%f 在 printf 中接收 double */
printf("%.1f\n", ratio);     /* 对：仍接收 double，只控制显示精度 */
```

对应写法是 `printf("%zu\n", bytes);` 和 `printf("%f\n", ratio);`。遇到编译器的 `-Wformat` 警告时，应修正类型或格式，不能通过强制转换掩盖错误。

## 7. snprintf：有容量限制的格式化写入

`snprintf` 在 `<stdio.h>` 中声明。它按照 `printf` 的格式规则生成文本，但把结果写入字符数组，而不是直接输出到终端：

```c
int snprintf(char *buffer, size_t capacity, const char *format, ...);
```

- `buffer`：接收结果的字符数组。
- `capacity`：`buffer` 可容纳的总字节数，**包括结尾的 `\0`**。
- `format` 和后续参数：用法与 `printf` 相同，格式说明符必须和参数类型匹配。

当 `capacity > 0` 时，最多写入 `capacity - 1` 个输出字节，并在已写内容末尾添加 `\0`。内容太长时，多出的部分会被丢弃；已写入的部分仍然以 `\0` 结束。`capacity == 0` 时不写入任何内容，`buffer` 可以是空指针。

### 判断是否写入完整

返回值是**假设缓冲区足够大时本来需要写入的字符数**，不包含 `\0`。因此它通常不同于实际放进数组的字符数：

- 返回值小于 `0`：格式化或字符编码发生错误。
- 返回值非负且小于 `capacity`：结果完整写入，且以 `\0` 结束。
- 返回值大于或等于 `capacity`：发生截断。缓冲区有容量时仍会以 `\0` 结束，但内容不完整。

例如，目标文本长度是 10，缓冲区容量是 8，`snprintf` 最多存下 7 个输出字节再加 `\0`，但返回值仍是 10。判断时要比较返回值和容量，而不是检查它是否非零。

```c
#include <stdio.h>

int main(void)
{
    char buffer[32];
    int score = 95;
    int written = snprintf(buffer, sizeof buffer, "score=%d", score);

    if (written < 0) {
        fputs("格式化失败\n", stderr);
        return 1;
    }
    if ((size_t)written >= sizeof buffer) {
        fputs("结果太长，已截断\n", stderr);
        return 1;
    }

    puts(buffer);
    return 0;
}
```

这里传入 `sizeof buffer`，让容量随数组大小自动更新。先检查负返回值，再将返回值转成 `size_t` 比较，避免把负数转换为很大的无符号数。截断有时可以接受，例如 UI 中的短标签；如果文本必须完整，应报告错误或换更大的缓冲区。

### 拼接已有字符串

`snprintf` 每次都会从目标缓冲区开头写入，不会自动追加。若要追加，必须先确认原字符串仍在数组范围内，再从末尾位置写入剩余容量：

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char message[32] = "score=";
    size_t used = strlen(message);
    size_t capacity = sizeof message - used;
    int written = snprintf(message + used, capacity, "%d", 95);

    if (written < 0 || (size_t)written >= capacity) {
        fputs("追加失败或结果被截断\n", stderr);
        return 1;
    }

    puts(message);
    return 0;
}
```

只有在 `message` 确实以 `\0` 结尾且 `used < sizeof message` 时，`message + used` 和剩余容量才有效。真实代码若 `message` 来自外部或旧操作可能截断，应先用有界方式确认终止符位置，再计算剩余空间。

### 常见注意事项

- `snprintf` 能限制写入的容量，不能替你检查格式符类型。`%d` 仍需 `int`，`%zu` 仍需 `size_t`；格式不匹配仍可能产生未定义行为。
- 格式字符串必须可信。不要写 `snprintf(buffer, sizeof buffer, user_text)`；用户文本中的 `%` 会被当作格式说明符。应写 `snprintf(buffer, sizeof buffer, "%s", user_text)`。
- 源字符串和目标缓冲区不能重叠。例如不要用 `snprintf(buffer, sizeof buffer, "%s!", buffer)` 原地扩展字符串；标准将重叠复制的行为规定为未定义。
- 容量以字节计，不是屏幕列数或 Unicode 字符数。UTF-8 文本被截断时，末尾可能留下不完整的多字节字符；完整性要求严格时应按编码边界截断或报错。
- `snprintf` 适合写入固定大小的缓冲区；无界的 `sprintf` 无法知道目标数组容量，应避免使用。
- `snprintf(NULL, 0, format, ...)` 可先查询完整结果所需的字符数（不含 `\0`），再分配足够空间并格式化。查询结果为负时应先处理错误；二次格式化时仍要检查返回值，并保证两次使用的格式和参数一致。

WG14 的 C23 工作草案规定：容量为零时不写入；容量非零时输出会被限制在 `capacity - 1` 个字符并补终止符；返回值表示完整结果长度。[标准条文](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf) 可用于核对这些细节。

## 练习

1. 输出一段包含双引号、反斜线和两行文字的字符串。
