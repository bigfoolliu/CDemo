# 主成分分析 PCA：从四维数据投影到二维

本案例对应 [学习计划阶段 9.4](deep_learning_plan.md)，源码为 `src/ml/18_pca.c`。它使用纯 C 和固定种子的合成数据，不读取外部数据，也不依赖机器学习框架。

运行 `./build/ml/18_pca` 查看训练集拟合出的均值、两个主方向、解释方差比例，以及训练集和独立测试集的重建误差。运行 `make pca` 会显示同样的数值，并把二维投影散点图保存到 `exports/`：蓝色点是训练集，橙色点是测试集。文件采用独占创建，不覆盖已有图片。图表范围也只依据训练集投影确定。

## PCA 的计算步骤

对训练样本 (x_i) 计算每个特征的均值 (mu)，再中心化 (x_i-mu)。接着计算协方差矩阵：

```text
C = (1 / N) Σ (x_i - μ)(x_i - μ)ᵀ
```

协方差矩阵的单位特征向量表示数据变化方向，特征值表示该方向上的方差。本例通过重复计算 `C × v` 并归一化来近似最大特征方向，这就是幂迭代。求第二方向时，每轮移除它在第一方向上的投影并重新归一化，从而得到正交方向；最后通过特征向量残差检查迭代结果。

样本投影为 `z = Vᵀ(x - μ)`，重建为 `x̂ = μ + Vz`，其中 `V` 的两行是两个主成分。前两个特征值之和除以总方差，给出二维投影保留的方差比例。案例还计算每个特征上的平均平方重建误差，便于观察压缩损失。

## 学习与实验

训练集和测试集由不同固定种子生成。拟合阶段只读取训练集；测试集只使用训练得到的均值和方向做投影与评估，避免数据泄漏。数据来自两个潜在变化方向并叠加小噪声，因此四个观测特征相关，二维空间应保留大部分方差。PCA 不读取类别标签，也不保证投影方向能区分类别。

可以尝试修改特征权重或噪声大小，观察主成分和重建误差如何变化；也可以把投影维数减为一维，比较压缩率与信息损失。当前示例固定为四个特征和两个主成分，适合跟踪矩阵与向量计算，不作为通用数值线性代数库。
