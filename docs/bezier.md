# 三次贝塞尔曲线编辑器

本示例用纯 C 计算和绘制曲线，SDL2 仅负责窗口、输入与画布呈现。适合学习结构体、数组、循环、浮点插值、鼠标交互和模块分离，不需要图形加速库或字体资源。

## 运行与操作

窗口沿用 [二维图形教程](graphics_2d.md) 的 SDL2、pkg-config 环境。在仓库根目录执行：

```sh
make bezier                  # 构建并启动窗口
make bezier-build            # 只构建，不打开窗口
make bezier-debug            # 独立的 -O0 -g3 调试程序
make compile-commands-graphics  # 更新包含 SDL 的代码提示
./build/graphics/bezier_demo --frames 120  # 显示 120 帧后退出
```

- **鼠标左键拖动**：在控制点附近按住左键，再移动鼠标；命中半径为 8 个逻辑像素。
- **R**：恢复初始曲线并清除选择。
- **S**：保存当前完整画布至 `exports/bezier-<时间>-<序号>.bmp`，不会覆盖旧图片；失败在终端报错，编辑器继续运行。
- **Esc / 关闭窗口**：退出并释放 SDL 资源。

绿色 **P0** 和红色 **P3** 是曲线端点；两个蓝色点 **P1/P2** 是内部控制点，通常不在曲线上。灰线连接四个点，形成控制多边形；青色线为曲线，黄色圆圈表示当前选择。窗口标题显示 P0..P3 的逻辑坐标和选择编号，`-1` 表示未选择。松开鼠标保留选择，点击空白清除选择。点重合或等距时选择编号较小者；后绘制的点可能遮挡前面的点，拖开后即可继续编辑。

## 曲线从哪里来

三次曲线有四个控制点，参数 `t` 从 0 变化到 1：

```text
B(t) = (1-t)^3 P0 + 3(1-t)^2 t P1 + 3(1-t)t^2 P2 + t^3 P3
```

端点满足 `B(0)=P0`、`B(1)=P3`。端点导数分别是 `3(P1-P0)` 和 `3(P3-P2)`，因此移动 P1/P2 会改变端点切线方向和曲线弯曲形状。导数可以为零，重合点也是有效输入。

代码采用等价的 **de Casteljau 算法**：先对相邻点做线性插值 `L(A,B,t)=(1-t)A+tB`，四个点变为三个点；再变为两个点，最后得到曲线上一点。`evaluate_unchecked` 使用局部数组 `work` 保存每层结果；循环从左到右覆盖，读取的右邻点仍属于上一层。

当 `t=0.5` 时，每层取相邻点的中点，最终得到曲线中点。所有步骤均为非负权重的平均，所以曲线位于控制点的凸包内。注意：参数中点不一定是弧长中点；均匀增加 t 不能保证沿曲线匀速移动。

## 坐标、拖动与绘制

逻辑画布为 **320×240**，默认窗口 **640×480**，左上角为原点，x 向右、y 向下。控制点范围为 `[0,319] × [0,239]`，允许小数；绘图时用 `lround` 四舍五入。SDL 鼠标和窗口尺寸使用相同单位，按像素中心映射：

```text
logical_x = (mouse_x + 0.5) * 320 / window_width - 0.5
logical_y = (mouse_y + 0.5) * 240 / window_height - 0.5
```

按下时保存 `offset = 控制点 - 鼠标逻辑坐标`；拖动时计算 `新位置 = 鼠标逻辑坐标 + offset`，避免点击方块边缘时跳动。新位置裁切到画布范围。松开左键、窗口失焦、鼠标离开窗口或移动事件不再含左键状态，都停止拖动；重新进入窗口后需要再次按下左键。

绘制均匀采样 128 段，将相邻样本用现有 `gfx_line` 连接。这是像素尺度的折线近似，没有自适应细分或抗锯齿。边缘控制点的方块和选择圆圈由绘图核心裁切。目标显示 **60 FPS**，只在控制点或选择改变时重新绘制，其余帧呈现缓存；系统调度、截图和绘制耗时会影响实际帧率。没有动画时间步，曲线参数 t 与帧率无关。

## 文件与接口契约

| 文件 | 职责 |
| --- | --- |
| `src/graphics/bezier.h/c` | 曲线结构、de Casteljau 求值、控制点修改、最近点命中与绘图 |
| `src/graphics/bezier_demo.c` | SDL 事件、拖动状态、帧率限制和 BMP 请求 |
| `tests/bezier_test.c` | 无窗口的数值与绘图验证 |
| `tests/bezier_window_test.c` | 合成输入、截图失败与主循环验证 |

曲线和画布均由调用者持有，核心不动态分配内存。接口拒绝空指针、NaN、无穷大、越界坐标与非法参数；`bezier_evaluate`、`bezier_move`、`bezier_draw` 失败时保留输出或原状态，`bezier_hit` 返回 `-1`。求值结果允许与控制点别名，计算使用局部副本。公共接口先验证，内部绘制再复用免重复验证的插值函数。

## 验证与学习练习

```sh
make test-bezier             # 端点、独立多项式、凸包范围、退化与失败行为
make sanitize-bezier         # 地址与未定义行为消毒器
make test-bezier-window      # 需 SDL2，dummy 驱动，无实际窗口
make test
make lint
```

窗口测试验证抓取偏移、两种缩放比例、四侧裁切、拖动取消、重复键、重置、截图和有限帧主循环；截图在临时目录测试，保留用户已有图片。

VS Code 选择 `C: 贝塞尔曲线编辑器` 按 F5，或运行任务 `C: 测试贝塞尔曲线核心`。建议按顺序练习：将四点放在直线上；让所有点重合；对照公式计算 `t=0.5`；在每层插值后绘制辅助线；最后尝试按曲率自适应细分。当前实现仅展示一条三次曲线，不含多段路径、撤销、持久化控制点或曲线匀速运动。
