# 文档阅读顺序

`docs/` 中的两位数前缀表示建议阅读顺序，并按主题留有编号间隔，方便后续插入教程。文档和配图文件名使用中文主题，专业术语在首次出现时同时标注中文、英文和常用缩写；正文标题按层级编号。各主题路线可以独立学习；第一次接触项目时，建议先读 C 基础与 Python 项目约定，再按兴趣选择图形、机器学习或深度学习路线。
