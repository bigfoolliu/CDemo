# 阶段 3：手写 CNN 识别灰度图形

源码：`src/ml/08_cnn_shapes.c`。在 [二维 MLP](mlp_2d.md) 的基础上学习局部连接、卷积核共享、最大池化和图像梯度。计算只使用 C 标准库与数学库；图片导出复用软件画布和 BMP 模块，不依赖 SDL 或外部机器学习框架。

## 运行、调试与输出

在仓库根目录运行：

```sh
make cnn-shapes                   # 数值验证、训练、独立评估并导出三张 BMP
make test-cnn-shapes              # 安静验证；不创建图片或日志
make sanitize-cnn-shapes          # 地址和未定义行为消毒器检查
./build/ml/08_cnn_shapes           # 输出训练过程，不写文件
```

默认构建、`make ml`、`make test` 和 `make lint` 自动包含此案例，不打开窗口或导出图片。训练每 10 轮显示一次指标，不创建文件日志；如后续增加持久日志，路径须位于 `logs/`。

VS Code 选择 `C: ml/08_cnn_shapes.c` 后按 F5，默认传入 `--export`。在 `convolution_at` 中观察小块点积；在 `network_forward` 中观察 `winners`；在 `network_backward` 中观察共享核梯度和输入梯度的累加。测试也会调用这些函数，可先在 main 的 `train` 调用处中断再单步进入。普通构建为 `-O2`，调试构建为 `-O0`。

## 1. 数据集与评估边界

程序生成 `16×16` 单通道图像，像素范围 `[0,1]`。三种标签是圆形、方形、朝上的等腰三角形，每类数量相同。各类共用这些随机范围：

- 中心 x/y 在 `[6.5,8.5)`，改变图形位置。
- 半径或半边长在 `[3,4.5)`，改变尺寸。
- 前景亮度在 `[0.8,1)`，每像素加入 `[-0.04,0.04)` 噪声，再裁切到 `[0,1]`。

训练集 180 张、验证集 90 张、测试集 90 张，分别使用种子 2025、2026、2027。只用训练集计算梯度；每轮用验证损失选择最佳参数；确定最佳参数后才计算测试指标。

这不是只识别三张固定模板，但仍是简单合成分布：图形不旋转、位置变化有限，类别面积也有差异。100% 测试准确率不证明网络具备通用形状识别、平移不变性或真实图像理解能力。

## 2. 从固定核开始理解卷积

先阅读 `convolution_at`：将 `3×3` 核与输入中的一个小块逐元素相乘再求和。移动核后重复使用同一组权重，即局部连接与权重共享。

严格说本例计算的是**互相关**，不翻转卷积核；深度学习通常也称它为卷积。卷积步长为 1，无填充（valid）：输出边长为 `16-3+1=14`，不访问图像范围外的像素。

边界测试输入为行优先的 1～256，核的九个权重均为 1：

```text
左上输出 = 1+2+3 + 17+18+19 + 33+34+35 = 162
右下输出 = 222+223+224 + 238+239+240 + 254+255+256 = 2151
```

展示还使用固定核 `[-1,0,1; -1,0,1; -1,0,1]`，观察左右灰度变化。固定核不参与训练；它帮助理解点积如何响应边缘。

## 3. CNN 的形状与参数

| 层 | 输出形状 | 可训练参数 |
| --- | --- | --- |
| 输入 | `1×16×16` | 0 |
| 四个 3×3 核与偏置 | `4×14×14` | `4×9+4=40` |
| ReLU | `4×14×14` | 0 |
| 2×2 最大池化，步长 2 | `4×7×7` | 0 |
| 展平 | 196 | 0 |
| 全连接与 softmax | 3 | `3×196+3=591` |

共 **631 个参数**。卷积数组采用通道优先布局：`channel*196+row*14+column`。池化输出也是连续的通道优先数组，展平只改变理解方式，不需要复制内存。

卷积核采用 He 均匀初始化，分类权重采用较小尺度，偏置置零，种子为 42。数据集使用静态存储区，避免三份固定容量图像数据占用过多栈；模型与缓存采用固定数组，不实现通用张量或动态形状接口。

## 4. 最大池化为什么需要缓存

一个池化窗口选取 `2×2` ReLU 激活中的最大值，保存其在卷积数组中的下标。反向时，窗口梯度只回到这个获胜位置。

平局时按行优先顺序选择第一个位置：只有候选值**严格大于**当前最大值才替换。测试使用全 1 图像和中心为 1 的核，验证平局下的前向位置和反向输入梯度。ReLU 在零点采用导数 0，另有零激活测试。

池化不是求平均，也不能把窗口梯度平均分给四个位置。这里窗口互不重叠，卷积小块则会重叠。

## 5. softmax、损失和反向传播

先从三个 logits 减去最大值，再求 softmax，避免大正指数溢出。交叉熵通过 log-sum-exp 计算：

```text
p[c] = exp(z[c]-max(z)) / Σ exp(z[k]-max(z))
L = max(z)-z[target] + log(Σ exp(z[k]-max(z)))
δ[c] = p[c] - I(c==target)
```

反向传播依次处理：

1. 全连接权重梯度 `δ[c]*pooled[i]`，偏置梯度为 `δ[c]`。
2. 池化输出梯度累加所有分类输出的路径：`Σ δ[c]*W[c,i]`。
3. 梯度路由到获胜位置，并通过 ReLU 的正数分支。
4. 卷积核梯度累加所有使用该核的位置：`dKernel[ky,kx] += δ*image[row+ky,column+kx]`。
5. 输入梯度累加重叠小块及不同通道的贡献：`dImage[pixel] += δ*Kernel[ky,kx]`。

不能将共享核的梯度写成最后一个位置的结果，也不能覆盖输入像素已收到的其他路径梯度。反向过程使用旧参数，完成后才更新。

## 6. 训练与实现验证

训练采用平均梯度、批量 12、Adam 学习率 0.003，共 80 轮，每轮打乱下标。打乱状态独立使用种子 2028；每轮 15 次更新，Adam 偏差修正按批次计数。最佳参数副本仅用于推理，不用于恢复优化器训练。

数值测试对全部 631 个参数和 256 个输入像素使用中心差分，`ε=1e-5`，结合绝对与相对误差。夹具采用严格正激活与单调输入，池化最大值唯一；每次正负扰动都检查 ReLU 分支和池化位置一致，避免拿不可微点的差分误判反向传播。

额外测试包含边界卷积手算、池化平局路由、ReLU 零点、分类平局和极端 logits 的稳定性。最终断言验证损失下降、独立测试准确率至少 80% 且交叉熵小于 0.6。数组容量与有限数值是内部接口前提，不提供非法指针、任意尺寸或 NaN 的自动恢复。

当前固定配置约得到：初始训练交叉熵 1.2126，最终训练损失 0.0034，验证准确率 98.9%，独立测试 90/90，交叉熵 0.0077。不同平台可能有小幅舍入差异；不同数据或种子不能保证相同结果。

终端混淆矩阵按真实类别为行、预测类别为列，顺序是圆形、方形、三角形，可用于观察哪些类别容易混淆。

## 7. 图片怎么读

显式导出会在 `exports/` 独占创建三张 `320×240` BMP，时间与序号防止覆盖：

- `cnn-shapes-samples-...bmp`：九张训练图，三列依次为圆形、方形、三角形，三行是不同样本。
- `cnn-shapes-initial-...bmp`：训练前的特征图。
- `cnn-shapes-best-...bmp`：验证集选出的最佳模型特征图。

两张特征图使用同一张验证圆形样本，按两行三列排列：第一行是输入、固定左右边缘核响应、学习通道 0；第二行是学习通道 1～3。输入按真实灰度展示，其余小图各自按最小/最大值归一化；常数图显示黑色。因此可比较响应位置，不能直接比较不同图的绝对激活强度。

这里展示的是卷积后 ReLU 激活，不应先假定某个通道必然代表边缘或某种类别。导出失败明确报错，保留已有文件；默认测试不创建图片。
