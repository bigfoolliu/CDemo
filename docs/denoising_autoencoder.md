# 阶段 4：去噪自编码器与瓶颈表示

源码：`src/ml/09_denoising_autoencoder.c`。在已有全连接网络基础上学习编码器、解码器、重建损失和去噪训练。采用纯 C、标准数学库及已有 BMP 绘图模块，不依赖机器学习框架或 SDL。

## 运行与调试

在仓库根目录运行：

```sh
make autoencoder                       # 验证、训练并导出三张重建对照 BMP
make test-autoencoder                  # 安静验证，不生成图片或日志
make sanitize-autoencoder              # 地址及未定义行为消毒器检查

```

默认构建、`make ml`、`make test`、`make lint` 已接入。普通构建使用 `-O2`；调试构建使用 `-O0`。每 25 轮显示一次指标，不创建文件日志；后续如增加持久日志，路径须位于 `logs/`。

VS Code 选择 `C: ml/09_denoising_autoencoder.c` 后按 F5，默认传入 `--export`。在 `network_forward` 查看 `activations[2]` 的前八个元素；在 `network_backward` 观察各层的 `delta` 和 `upstream`；在 `corrupt_sample` 检查 clean 保持不变。入口先执行完整梯度验证，再训练；只想观察训练时，先在 main 的 `train` 调用处设置断点。

## 1. 与分类网络有什么区别

分类网络输出类别，自编码器输出与输入同尺寸的重建图像：

```text
带噪图 x(256)
 → 编码器：32 个 tanh 神经元 → 8 维 tanh 瓶颈 h
 → 解码器：32 个 tanh 神经元 → 256 个 sigmoid 像素 y
```

训练目标是干净图像，而不是复制带噪输入。前三个非线性层使用 tanh，输出层 sigmoid 保证像素在 `[0,1]`。瓶颈只有八个数，迫使网络学习本数据中可复用的结构。

瓶颈不是预设的“类别、位置、尺寸”字段，不能保证某一维具有固定含义。解码器也不是编码器的严格数学逆函数；噪声破坏的信息不能保证完全恢复。

## 2. 参数形状与内存组织

| 层 | 权重形状 | 偏置数 | 参数数 |
| --- | --- | --- | --- |
| 编码第一层 | `32×256` | 32 | 8224 |
| 编码瓶颈层 | `8×32` | 8 | 264 |
| 解码第一层 | `32×8` | 32 | 288 |
| 解码输出层 | `256×32` | 256 | 8448 |

总计 **17224 个参数**。权重按输出神经元逐行存放，`Layer` 描述输入宽度、输出宽度和扁平参数数组的偏移。它只描述本例的固定四层网络，不是通用框架。

`Forward.activations` 保存各层前向值，第 0 行是输入，第 2 行是瓶颈，第 4 行是重建。每行容量为 256，实际只读写当前层宽度的元素。三个图像集合使用静态存储区，模型和梯度用固定数组，避免动态分配与所有权复杂度。

所有内部接口要求有效指针、足够容量和有限数值，缓冲区不重叠；参数及中间计算不能溢出。代码注释说明各函数的长度与修改范围，不提供任意形状、非法指针或 NaN 的恢复机制。

## 3. 数据、噪声与集合划分

生成 `16×16` 二值圆形、方形和朝上三角形。中心 x/y 在 `[6.75,8.25)`，半径或半边长在 `[3,4)`。类别交替，仅用于生成不同图像，不将类别标签作为网络输入。

每个像素以 20% 概率翻转 `0↔1`，再加入 `[-0.16,0.16)` 灰度扰动，裁切到 `[0,1]`。`Sample` 分开保存 `clean` 和 `noisy`，噪声生成函数只修改后者。

| 集合 | 样本数 | 图形种子 | 初始噪声种子 |
| --- | --- | --- | --- |
| 训练 | 96 | 2025 | 3025 |
| 验证 | 48 | 2026 | 3026 |
| 测试 | 48 | 2027 | 3027 |

初始化种子为 42，打乱种子为 2028。训练每轮使用持续推进的独立噪声状态 4025 重新污染图像，防止只拟合固定损坏模式。干净训练图保持不变；验证和测试噪声固定，便于公平比较各轮模型。

只用训练集计算梯度，验证损失选择最佳参数，最后用未参与选模的测试集评估。前后对照的验证图片也使用相同输入和目标。

## 4. MSE 与反向传播

单图损失是逐像素平均平方误差，不乘 `1/2`：

```text
L = Σ_i (y_i-clean_i)² / 256
dL/dy_i = 2*(y_i-clean_i)/256
输出层 δ_i = dL/dy_i * y_i*(1-y_i)
```

然后逐层反向：

```text
dW[out,in] = δ[out] * 上一层激活[in]
db[out] = δ[out]
upstream[in] = Σ_out δ[out] * W[out,in]
隐藏层 δ[in] = upstream[in] * (1-activation[in]²)
```

传播到输入时不再乘 tanh 导数，因为输入未经过该激活。网络先计算所有梯度，再更新参数；每批梯度除以实际批次大小。训练使用 Adam 0.003、批量 8、400 轮，每轮 12 次更新。

像素平均与样本平均是两次不同归一化，不能漏掉 `1/256`，也不能将 MSE 的输出梯度误用为交叉熵的 `p-y`。本例输出使用 sigmoid，因此还必须乘它的导数。

## 5. 实现验证与独立评估

运行时首先执行：

- 对全部 17224 个参数及 256 个输入像素进行中心差分检查，`ε=1e-5`，结合绝对与相对误差。
- 验证 sigmoid 极端值、已知 MSE、固定噪声复现、干净目标不变，以及单样本尾批与单样本梯度一致。
- 从独立初始化副本拟合三张固定图，验证损失明显下降；这是计算诊断，不用于证明泛化，也不作为正式训练的预训练参数。

正式训练后，对同一测试集报告三种 MSE：

| 方法 | 当前固定配置的近似 MSE |
| --- | --- |
| 直接保留带噪输入 | 0.18976 |
| 输出训练集的平均干净图 | 0.03990 |
| 自编码器重建 | 0.01553 |

平均图只从训练集计算，不能使用测试目标构造基线。断言要求重建优于两种基线，并保留适当误差余量。当前固定验证 MSE 约为 0.01541；这些数值是小型合成任务的一次实验，不保证其他图像或噪声分布上的表现。

优化等级和数学库的舍入差异也可能逐步改变训练轨迹：本机消毒器构建的测试重建 MSE 约为 0.01637，仍通过同样的验证标准。不要求不同构建逐位复现损失。

MSE 会鼓励模糊、平均化的像素预测。降低误差不等于所有边缘、位置和形状细节都恢复；因此同时观察图片。初期损失可能接近平均图基线，瓶颈 tanh 也可能接近饱和，都是值得用断点研究的现象。

## 6. 图片与瓶颈怎么观察

显式导出在 `exports/` 独占创建三张 `320×240` BMP，保留历史文件：

- `autoencoder-initial-...bmp`：初始网络在验证样本上的输出。
- `autoencoder-best-...bmp`：最佳网络在相同验证样本上的输出。
- `autoencoder-test-...bmp`：最佳网络在独立测试样本上的输出。

每张三行分别选取圆形、方形、三角形；三列依次为 **带噪输入、模型重建、干净目标**。所有图使用相同灰度尺度，不单独拉伸对比度。导出失败明确报错，普通测试不创建图片或日志。

终端显示首张测试图的八维瓶颈。改变输入后观察它如何变化，但不要把这些数直接解释为类别概率。自编码器不等于图片压缩文件格式：完整恢复还需要解码器参数、量化、编码规则与误差评估，本例不实现这些内容。
