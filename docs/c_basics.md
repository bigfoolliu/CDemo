# C 语言基础学习手册

本手册按初学者的学习顺序组织。先学习基础语法和对象模型，再学习 C23 的新增写法。示例是主题入口，不等同于标准的全部细节；末尾列出尚未提供独立示例的内容。

## 1. 程序如何运行

```c
#include <stdio.h>

int main(void)
{
    puts("你好，C");
    return 0;
}
```

`#include` 引入声明，`main` 是普通宿主环境的入口，花括号组成语句块，分号结束声明或表达式语句。`return 0` 表示成功退出。`//` 是行注释，`/* ... */` 是块注释，块注释不可嵌套。

构建通常经历预处理、编译、汇编和链接。每个源码经过预处理形成一个翻译单元；链接器将不同翻译单元中的定义组合起来。声明介绍名字和类型，定义提供函数实现或对象；文件作用域的暂定定义另有规则。

练习：将 `puts` 替换为 `printf`，使用 `\n` 换行，观察少写分号时的编译诊断。

## 2. 类型、变量与初始化

阅读 `src/basics/01_types.c`。

- 整数包括 `char`、`short`、`int`、`long`、`long long` 及相应无符号类型。普通 `char` 的符号性由实现决定。
- 浮点类型包括 `float`、`double`、`long double`。许多十进制小数不能精确表示，比较时要考虑误差。
- C23 的 `bool` 表示真假；`void` 可表示函数无返回值，`void *` 可表示通用对象指针。
- `const` 限制修改，不等于所有场景中的编译期常量。`volatile` 不提供线程同步，`restrict` 是指针访问约定，不能随意添加。
- 自动局部对象未初始化时不要读取；静态存储期对象默认进行零初始化。
- `sizeof` 返回 `size_t`，`sizeof(char)` 总是 1；每字节位数由 `CHAR_BIT` 给出。不要假设 `int` 永远为 32 位。
- `<stdint.h>` 提供固定宽度整数类型，但精确宽度类型是否存在取决于实现；格式化输出可使用 `<inttypes.h>` 的宏。

练习：输出不同类型的大小，给变量设置初始值，再观察整数转为浮点数后的结果。

## 3. 表达式与运算符

阅读 `src/basics/02_operators.c`。

算术运算有 `+ - * / %`，比较有 `== != < <= > >=`，逻辑有 `! && ||`，位运算有 `~ & | ^ << >>`。另有赋值和复合赋值、前后缀递增递减、条件运算符 `?:`、逗号运算符、下标、成员访问、取地址、解引用及强制转换。

整数除法向零截断；除数不能为零。有符号整数溢出是未定义行为；无符号算术按模数回绕。移位位数不能为负，也不能达到或超过提升后左操作数的位宽。位操作优先使用无符号类型。

窄整数会经历整数提升；不同类型参与运算时还有通常算术转换。混合有符号和无符号数可能改变比较结果。强制转换不能让无效地址变成有效指针。

优先级决定表达式如何组合，不保证操作数的求值顺序。不要写 `i++ + i++`，也不要依赖函数实参从左到右求值。逻辑运算短路；用括号明确复杂表达式的意图。

练习：预测 `7 / 2` 与 `(double)7 / 2`，比较 `&&` 与 `&` 的行为。

## 4. 语句与控制流

阅读 `src/basics/03_control_flow.c`。

`if/else` 做条件分支，`switch/case/default` 做整数条件分支；`for`、`while`、`do/while` 做循环。零为假，非零为真。`break` 结束最内层循环或 switch，`continue` 进入下一轮循环，`return` 返回调用者。

`switch` 的 case 是整数常量表达式；它不会自动停止，需明确处理贯穿执行。`goto` 跳到当前函数中的标签，可用于统一清理资源；不应用它绕过对象初始化后继续读取对象。

练习：累加 1 到 100，跳过偶数，再用 switch 区分不同选项。

## 5. 函数与接口

阅读 `src/basics/04_functions.c`、`src/basics/12_generic_variadic.c`。

函数声明包含返回类型、名字和参数类型；定义另包含函数体。采用 `int f(void)` 明确无参数。C 按值传参，修改调用者对象需要传递地址。数组参数会调整为指针，因此长度应单独传递。

递归必须有终止条件，并考虑调用深度与运算溢出。函数指针可用于回调。可变参数使用 `<stdarg.h>`，调用者必须遵守数量和类型协议；`float` 会提升为 `double`，窄整数经历整数提升。`_Generic` 按类型选择表达式，不是模板。

练习：编写求数组最大值的函数，明确空数组时的返回协议。

## 6. 数组与字符串

阅读 `src/basics/05_arrays_strings.c`。

数组是一组连续的同类型元素，索引从 0 开始，没有自动边界检查。数组不能直接整体赋值；多维数组是数组的数组。指定初始化可使用 `[index] = value`；部分初始化时，剩余元素进行零初始化。

字符串是以 `\0` 结束的字符序列。`strlen` 不计算终止符，`sizeof` 对字符数组计算整个对象大小。字符串字面量不可修改；`char text[] = "abc"` 创建可修改的副本。中文 UTF-8 文本占多个字节，`strlen` 计算字节数，不是可见字符数。

`strcmp` 比较内容，不能用指针的 `==` 代替。格式化写入检查 `snprintf` 的返回值，以识别错误或截断。

练习：遍历二维数组，用 `snprintf` 拼接字符串，并检测缓冲区过小的情况。

## 7. 指针与对象生命周期

阅读 `src/basics/06_pointers.c`。

`&object` 取地址，`*pointer` 访问对象。指针有类型，指针加一移动一个元素。算术与大小比较应限制在同一数组及其尾后位置内；尾后指针不能解引用。

数组和指针是不同的类型：真实数组的 `sizeof` 得到数组大小，指针的 `sizeof` 得到指针大小。`const int *` 限制通过该指针改值，`int *const` 限制指针本身改指向。二级指针可用于修改调用者持有的指针。

不要解引用空指针、未初始化指针或失效指针，不要返回自动局部对象的地址。指针转换还需要满足对齐及对象访问规则；不要通过随意转换类型的指针读取其他类型对象。

练习：用指针交换两个变量，比较数组下标访问与指针访问。

## 8. 自定义类型

阅读 `src/basics/07_aggregate_types.c`。

`struct` 组合不同成员，使用 `.` 或 `->` 访问；可能包含对齐填充，不能假设大小等于成员大小之和。结构体赋值复制成员，指针成员仍指向原地址。`union` 的成员共享存储；初学时使用显式标签记录有效成员。`enum` 提供命名的整数值，`typedef` 提供类型别名。

复合字面量可创建匿名对象；其存储期取决于所在位置。位域用于表达有限位宽的成员，但布局与顺序有实现相关规则，不宜直接当作网络协议格式。柔性数组成员用于结构体尾部的可变长数据，需要额外分配空间。

练习：定义学生结构体和学生数组，用枚举表示状态。

## 9. 作用域、存储期与链接

阅读 `src/basics/08_scope_storage.c`、`src/modules/`。

作用域决定哪里能使用名字，存储期决定对象存在多久，链接决定不同声明是否指同一实体。三者应分开理解。

普通局部对象有自动存储期；静态局部对象跨调用保存状态。文件作用域的 `static` 限制内部链接；公共函数及通常的文件作用域对象有外部链接，可用 `extern` 声明其他文件中的对象。动态分配对象具有分配存储期；`thread_local` 对象具有线程存储期。

头文件放接口声明，源文件放实现，通过包含保护防止重复包含。不要在头文件中随意定义具有外部链接的普通对象或函数。

练习：给多文件示例添加减法接口，比较修改声明和修改实现导致的编译或链接错误。

## 10. 动态内存

阅读 `src/basics/09_dynamic_memory.c`。

`malloc` 分配未初始化的内存，`calloc` 将分配的字节清零，`realloc` 调整分配大小，`free` 释放。字节全零不能普遍当作所有类型的语义零值，如浮点数或空指针。

检查分配失败和大小乘法溢出。使用临时指针接收 `realloc`；失败时保留原分配，成功时停止使用旧指针。C23 下不要将零大小传给 `realloc`。

明确内存所有权，保证每个分配最终释放一次。释放后读取、重复释放、越界和遗漏释放都应避免。给一个指针赋空值不会修复其他悬空别名。

练习：实现动态整数数组，增加容量和失败处理。

## 11. 预处理与构建

阅读 `src/basics/10_preprocessor.c`。

`#include` 引入内容，`#define` 定义宏，`#undef` 取消宏，`#if/#ifdef/#ifndef/#elif/#else/#endif` 控制条件编译。`#` 可将宏参数字符串化，`##` 可拼接记号。宏不遵循普通函数调用规则，尤其要防止重复求值；计算逻辑优先用函数。

`__FILE__`、`__LINE__` 可用于定位信息；`__STDC_VERSION__` 表示实现声明的标准版本。`#error` 可拒绝不满足要求的配置，`#pragma` 常涉及实现相关行为。

练习：运行 `cc -std=c23 -E src/basics/10_preprocessor.c` 查看预处理结果。

## 12. 输入输出与错误处理

阅读 `src/basics/11_io_errors.c`。

`printf` 的格式必须匹配参数类型，`%zu` 用于 `size_t`，`%p` 配合 `void *`。读取文本优先使用限制长度的 `fgets`，再通过 `strtol` 等解析，并检查末尾指针、范围和 `errno`。不要将用户文本直接当作格式字符串。

文件操作遵循打开、读写、定位、关闭的流程。检查返回值，用 `feof` 区分结束、`ferror` 判断错误；`fgetc` 的返回值应存入 `int` 才能区分字符与 `EOF`。不能用 `while (!feof(file))` 预测下一次读取是否成功。

`assert` 用于验证程序内部假设，不能替代输入或资源错误处理。普通错误通过返回状态、输出参数或错误对象向调用者传递。`main(int argc, char *argv[])` 可接收命令行参数。

练习：解析命令行中的整数，拒绝非法字符、超范围值及缺失参数。

## 13. C23 新特性

基础学习完成后，运行根目录三个 C23 示例，理解关键字 `bool`、`nullptr`、`static_assert`、二进制字面量、数字分隔符和 `_BitInt`。

后续新增示例应逐项验证 `constexpr`、`typeof`、`typeof_unqual`、`auto` 类型推导、标准属性、`#embed`、`<stdckdint.h>` 与 `<stdbit.h>` 的工具链支持。
