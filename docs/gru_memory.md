## 1. 记忆比特任务

序列只有五种 one-hot 输入：0/1 表示起始比特，2/3 是与标签无关的噪声符号，4 表示结束。例如：

```text
输入：1 → 2 → 3 → 2 → 4
目标：在读到最后的4之后，预测开头的1
```

噪声间隔 gap 不包含起始和结束符，总时间步数为 `gap+2`。只在最后一步计算 sigmoid 二分类交叉熵，中途没有额外监督；不能直接把起始比特传给输出层。每条独立序列从零隐藏状态开始，前一条序列的记忆不会传到下一条。

两个模型都用八维隐藏状态。RNN 有 121 个参数，GRU 有 345 个参数；固定数组最多容纳 32 个噪声符号、34 个时间步和 128 条序列。数据生成检查长度、容量和偶数样本数，失败保留原数据。标签严格平衡，始终预测一个类别的准确率为 50%，输出概率0.5的 BCE 为 `log(2)`。

## 2. GRU 前向公式与参数形状

本例使用 **reset-before** 候选状态，更新门 z 表示保留旧状态的比例：

```text
z = sigmoid(W_z x + U_z h_prev + b_z)
r = sigmoid(W_r x + U_r h_prev + b_r)
n = tanh(W_n x + U_n (r ⊙ h_prev) + b_n)
h = z ⊙ h_prev + (1-z) ⊙ n
```

这里 ⊙ 是逐元素乘法。z 接近1时保留旧状态，接近0时更多使用候选状态；r 决定候选计算使用多少旧信息。它们都是从数据学习的连续值，不是手写的开关。

每组 W 为 `8×5`，U 为 `8×8`，偏置为8，合计112个参数；三组共336个，加8个输出权重和1个输出偏置，得到345个参数。RNN 只用一组 tanh 参数，再加输出层，得到121个。所有权重按输出行优先排列，one-hot 输入等价于取 W 的一列。

门先完整计算，再计算候选状态，因为候选的每个输出会使用所有 `r[j]`。本例把重置操作放在循环矩阵乘法之前；`U_n(r⊙h)` 与 `r⊙(U_n h)` 通常不相等，阅读其他实现时要先确认变体以及更新门的方向约定。

## 3. 反向传播中新增的路径

输出层只在终点产生 `dlogit = probability-label`，再将隐藏梯度沿整个序列倒序传播。给定当前隐藏梯度 dh：

```text
dn = dh ⊙ (1-z)
dz_pre = dh ⊙ (h_prev-n) ⊙ z ⊙ (1-z)
dn_pre = dn ⊙ (1-n²)
v = U_n^T dn_pre
dr_pre = (v ⊙ h_prev) ⊙ r ⊙ (1-r)
dh_prev = dh ⊙ z + v ⊙ r + U_z^T dz_pre + U_r^T dr_pre
```

第一项 `dh⊙z` 是状态混合的直接保留路径。候选矩阵梯度为 `dn_pre (r⊙h_prev)^T`，重置门梯度需要先收集所有候选行的贡献；因此代码先累计 dr，再处理重置门。所有时间步的门与候选参数梯度使用 `+=`，全部 BPTT 完成后才能更新参数。

这种路径允许门控调节信息和梯度的保留，但不保证任意长度都能记住，也不保证训练一定成功。当前仅实现完整 BPTT，没有截断或 LSTM 的独立细胞状态。

## 4. 比较实验的控制变量

对 gap=2、8、24，分别使用初始化种子42和123，每个条件训练 RNN 与 GRU：

- 隐藏宽度都是8；Adam 学习率0.01，梯度全局 L2 裁剪阈值1。
- 都训练300轮，每轮32条平衡序列，每条只有一个终点损失。
- 第 e 轮使用噪声种子 `4000+e`（e 从0开始），两模型收到完全相同的数据；每轮重建噪声，避免仅背固定样本。
- 验证集32条、种子2026；测试集128条、种子2027。每轮只用验证 BCE 选择检查点，最终测试不参与选择。

同预算指相同数据量、更新次数及优化器配置，不表示相同参数量或计算量。不同结构的随机参数数量不同，相同初始化种子也不意味着对应参数逐个相同。

训练、验证和测试采用分别生成的完整序列，无窗口跨分组边界；短间隔的可能序列很少，重复内容不可避免。这是独立噪声下的合成任务评估，不是未知语言或所有长期依赖的泛化证明。

Apple Clang 17 下的固定实验结果：

| gap | 初始化种子 | RNN测试准确率 | GRU测试准确率 |
| --- | --- | --- | --- |
| 2 | 42 | 100% | 100% |
| 2 | 123 | 100% | 100% |
| 8 | 42 | 100% | 100% |
| 8 | 123 | 100% | 100% |
| 24 | 42 | 100% | 100% |
| 24 | 123 | 53.12% | 42.19% |

最后一行的测试 BCE 分别为0.68760与0.69439。这个预算下两个模型都有种子敏感性，GRU 并非必然胜出；两个种子也不足以形成可靠的统计结论。数值回归测试要求短间隔学会任务，长间隔只检查指标合法并如实报告结果，不用“GRU必须更好”的断言强制结论。

默认展示 gap=24、种子42 的两条测试序列。在起始、中点和结束位置输出第一个隐藏分量；GRU 额外输出 z/r 的八维均值。均值只用于观察，不能单凭它证明每个隐藏分量如何编码比特。最终输出概率应结合标签、完整状态和独立测试指标理解。

## 5. 验证与下一步练习

数值检查使用三步展开及非零初始状态，对 RNN 的全部121个参数、GRU的全部345个参数以及各自8个初始隐藏值做中心差分。这样可同时检查时间共享、更新门、重置门、候选状态和初始状态导数，而不是只验证输出层。

边界断言还覆盖：零参数时 z=r=0.5、每步状态减半；极端更新门保留或替换状态；稳定 sigmoid/BCE；最长序列的前向与反向；非法长度、标记和标签；状态重置；裁剪及非有限更新拒绝。固定容量缓冲区由调用者拥有，无动态分配或模型文件输出。

建议先画出直接保留路径，再修改 gap 或增加初始化种子，记录多个运行结果。改变学习率、隐藏宽度或训练预算时，用验证集选择配置，保留最终测试集。LSTM 可在此基础上选做，重点区分隐藏状态和细胞状态；主线下一步是阶段 7 的小型 Transformer。
