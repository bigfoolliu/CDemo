# 三维粒子玫瑰

本例用纯 C 将 16,000 个带深度的粒子投影到二维像素画布，表现成粉白体积花云、柔和发光、缓慢旋转与向下飘散的细粒子。深色背景和低对比中心轴线参考 `exports/rose_demo.jpg`；SDL2 只处理窗口、输入、计时和区域呈现，不负责粒子绘制。核心位于 `src/graphics/rose3d.h/c`，交互入口为 `src/graphics/rose3d_demo.c`。

运行 `make rose` 启动，`make rose-build` 仅构建，`make rose-debug` 构建调试版本。显示窗口为 340×480 像素，内部逻辑画布仍为 320×240；中心 170×240 区域按竖屏比例放大。程序目标为 60 FPS，模拟采用固定 1/60 秒步长，实际帧率会受绘制和系统调度影响。`./build/graphics/rose3d_demo --frames 120` 可运行 120 帧后退出。

| 操作 | 行为 |
| --- | --- |
| 左右方向键 | 手动调整水平观察角度 |
| 上下方向键 | 调整俯仰角，限制在 ±1.2 弧度 |
| Space | 暂停或继续动画 |
| N | 暂停时推进一个固定模拟步 |
| R | 使用固定种子重新生成粒子 |
| S | 将竖屏图像保存到 `exports/`，不覆盖已有文件 |
| Esc / 关闭窗口 | 释放 SDL 资源并退出 |

## 粒子采样与运动

玫瑰曲线的周期项 `|cos(5θ/2)|` 为花瓣提供五瓣轮廓，径向随机量的平方根使样本较均匀地填充花瓣区域。每个点再加入不同深度的扰动，花朵因此成为有体积的云团。少量粒子从花冠下方的逐渐变窄区域采样，形成散开的尾迹。颜色在柔和的玫粉到暖白之间变化。

粒子使用固定容量数组，不进行逐帧堆分配。每个粒子拥有小幅速度、漂移相位和生命周期；到期后从花瓣或尾迹重新采样。系统内的伪随机数生成器使相同种子可重现相同初始状态，便于对照实验和断点调试。

## 投影与发光合成

粒子先绕 Y 轴旋转，再按俯仰角绕 X 轴旋转。相机深度决定透视缩放：

```text
screen_x = center_x + focal_length * x / depth
screen_y = center_y - focal_length * y / depth
```

投影点向固定光照缓冲写入 3×3 加色光斑，邻近粒子自然叠成较亮的花瓣中心。最终通过软限幅映射回 8 位 RGB，降低过曝区域的硬边。所有落点先做有限值和边界检查；只把中心竖屏矩形写入逻辑画布。

SDL 呈现接口可从完整纹理选择源矩形并缩放到窗口。BMP 编码也支持指定画布区域，所以按 S 保存的截图与竖屏显示内容一致，尺寸为 170×240，而不是把整张 320×240 横屏画布塞进图片。`exports/` 内采用时间戳和序号命名，并以独占方式创建文件。

主循环将墙钟时间累积成固定模拟步，单帧最多接纳 0.1 秒，暂停或重置时清除时间余量。目标显示速率为 60 FPS；这是限速目标，并非所有机器上都能保证达到的刷新率。

## 测试与学习练习

`make test-rose3d` 验证相同种子、固定步进及竖屏绘制；`make sanitize-rose3d` 检查核心内存和未定义行为。`make test-rose3d-window` 用 SDL dummy 驱动验证控制与真实 BMP 截图，不需要打开可见窗口。SDL2 和 pkg-config 仍是编译窗口所需依赖。

建议按 `rose3d.h → rose3d.c → rose3d_demo.c → graphics_sdl.c → bmp.c` 阅读。可以逐步调整粒子数、尾迹比例、深度扰动、光斑权重和色调映射，观察性能与云雾质感的变化；也可暂时关闭漂移，比较固定点云与生命周期重采样的差异。VS Code 选择 `C: 三维粒子玫瑰` 按 F5 调试，运行 `make compile-commands-graphics` 更新 clangd 编译数据库。
