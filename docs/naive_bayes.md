# 朴素贝叶斯文本分类

这个案例对应 [学习计划阶段 9.1](deep_learning_plan.md)。源码为 `src/ml/15_naive_bayes.c`，复用 `src/common/word_map.h` 统计词频；只依赖 C 标准库与数学库，不读取外部数据，也不写文件。

```sh
make naive-bayes
make test-naive-bayes
make sanitize-naive-bayes
```

## 先看数据与分词

训练集含 12 条英语短句，两类各 6 条：类别 0 是普通消息，类别 1 是促销消息。测试集另有 6 条句子，不参与建词表和估计概率。程序还报告“始终猜类别 0”的基线，便于判断分类器是否学到了超出先验的内容。这只是固定小数据上的实现验证，不能代表真实垃圾邮件识别效果。

分词沿用词频案例的规则：连续 ASCII 字母组成一个词，大写转小写，其余字节都是分隔符。`FREE123free` 因而得到两个 `free`；UTF-8 中文不会成为词。每个词在文本中出现几次就计几次，这对应**多项式**朴素贝叶斯。哈希表复制词键，临时分词缓冲在回调后释放；模型销毁时释放所有键。

## 手算一次预测

对类别 `c` 和训练词表里的词 `w`，先计算：

```text
P(c) = 该类训练文档数 / 全部训练文档数
P(w | c) = (该类中 w 的出现次数 + 1) / (该类总词数 + 词表大小)
score(c, text) = log P(c) + 文本中每个已知词的 log P(w | c) 之和
```

加一是拉普拉斯平滑：某词只在另一类出现时，条件概率仍大于零。使用对数把多个很小概率的连乘变为连加，避免下溢。两类分数都未归一化，但比较大小足以分类；相等时选择类别 0。这里假设给定类别后，词的出现相互独立。这是便于计算的模型假设，现实语言通常不满足。

例如训练文档为 `"HAM ham!" → 0` 与 `"spam" → 1`，词表大小为 2。预测 `"HaM"` 时，两类先验均为 `1/2`：类别 0 的 `ham` 条件概率是 `(2+1)/(2+2)=3/4`，类别 1 是 `(0+1)/(1+2)=1/3`。因此类别 0 得分 `log(1/2)+log(3/4)`，高于类别 1 的 `log(1/2)+log(1/3)`。

## 行为边界与验证

- **未登录词**：预测时忽略训练词表之外的词，不扩大分母；空文本或全是未登录词时仅比较先验。训练集中两个类别都至少需要一篇文档，整个词表必须非空。
- **失败行为**：训练先写入临时模型；遇到无效标签、空文本指针或分配失败时释放临时数据，旧模型保持不变。预测失败不修改输出结构。
- **测试**：专项测试核对手算分数、重复词、大小写、数字分隔、类别先验、未登录词及失败保留；`make test` 和 `make lint` 也包含此案例。`make ml` 会在其他案例之后运行它。

练习：让两类训练文档数量不等，观察空文本的结果；增加同一个词的次数，观察两类对数分差；把未登录词规则改成明确的 `<UNK>` 类别，再重新推导训练时的词表和分母。调整短句后仍应把测试集留在训练流程之外。
