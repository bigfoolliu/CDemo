## 1. 从确定编码到概率编码

普通自编码器为每张图输出固定潜在坐标。VAE则编码一个对角高斯分布：`q(z|x)=N(mu(x), diag(exp(logvar(x))))`。两个输出分支都可学习，logvar表示方差的对数，不是标准差的对数。

```text
256像素 → 32(tanh) → mu(2)、logvar(2)
sigma = exp(0.5*logvar)
z = mu + sigma ⊙ epsilon，epsilon ~ N(0,I)
z(2) → 32(tanh) → 256(sigmoid像素概率)
```

共16900个参数，权重按 `[输出][输入]` 行优先排列。固定容量数组由调用方拥有，无动态分配。独立训练/验证/测试图形为96/48/48张，均衡包含圆、方、三角，位置和尺寸采用阶段4的同类变化范围；本例没有加入去噪任务。

训练图形种子2025，验证2026，测试2027，参数初始化42。训练epsilon随机状态从4025持续推进；Box-Muller使用开区间(0,1)均匀数，避免log(0)，每次产生两个标准正态值。

## 2. 为什么需要重参数化

直接把随机抽样作为一个黑盒，无法沿抽样操作直接回传参数导数。改写为 `z=mu+sigma*epsilon` 后，将随机性放在独立epsilon中，网络仍通过确定的运算接收导数。

一次前向和反向使用同一epsilon；数值差分的正负扰动也必须使用相同epsilon，否则损失差含随机噪声，无法验证导数。训练时每个样本重新采样；推理可解码mu（epsilon=0），或继续从后验采样。**解码mu不等于解码输出的期望**，因为解码器是非线性的。

为限制指数运算范围，输出分支使用光滑参数化 `logvar=6*tanh(raw/6)`，将logvar限制在[-6,6]。它限制了可表示的后验方差，也可能在饱和处使导数变小；不是没有影响的兼容技巧。反向必须乘 `1-tanh(raw/6)^2`，不能忽略这一层或当作硬裁切。

## 3. 重建似然、KL与负ELBO

输出sigmoid表示每个二值像素为1的概率，不直接随机采样黑白像素；展示灰度概率便于观察不确定区域。假设给定z后像素条件独立，重建项为每图像素BCE之和：

```text
reconstruction = sum_pixel(softplus(logit) - x*logit)
KL = 0.5 * sum_latent(mu² + exp(logvar) - 1 - logvar)
训练损失 = reconstruction + KL
```

这是标准正态先验下、beta=1的负ELBO单次采样估计。重建项鼓励解释输入，KL惩罚后验偏离标准正态，便于从先验生成。KL不是让所有样本“强制完全相同”的规则；两项需要平衡。若改成平均像素BCE却仍加同一个KL，相当于大幅加强KL相对权重，不是单纯换显示单位。

代码用稳定softplus计算BCE，避免对下溢概率取log；KL用 `expm1(logvar)-logvar` 改善靠近零时的消减误差。MSE只用于直观比较重建，并不参与训练。

VAE的概率建模和重参数化原理可参考[原始论文](https://arxiv.org/abs/1312.6114)。本例是固定合成图形上的小型教学实现。

## 4. 反向传播与验证

设解码器传回dz：

```text
dmu = dz + mu
dlogvar = dz * 0.5*sigma*epsilon + 0.5*(exp(logvar)-1)
draw = dlogvar * (1-(logvar/6)²)
depsilon = dz * sigma
```

前一部分来自重参数化重建路径，后一部分来自KL；均值和方差分支同时回到编码器隐藏层。完成整个批次反向后才更新参数。

内置中心差分检查全部16900个参数、256个输入以及2个epsilon导数。输入检查对同一个x同时作为编码输入和重建目标的总函数求导，因此包含BCE目标项的 `-logit` 导数；这不同于“固定目标，仅扰动编码输入”。检查使用内区间灰度值，避免扰动越过[0,1]。

解析断言覆盖标准正态KL=0、mu非零时KL、重参数化、logvar上下边界、稳定像素logit、采样可重复、裁剪和非有限更新失败不部分修改。

## 5. 训练与独立评估

使用250轮、批量8、Adam学习率0.003、全局梯度裁剪5。每个训练样本每次使用新的epsilon。固定验证随机种子5025，每张图4次采样，按平均重建NLL+KL选择检查点；KL可解析计算，不靠抽样估计。最终测试同样采用可重复评估噪声，不参与参数或检查点选择。

另外用epsilon=0计算确定的均值重建MSE，对照仅从训练集计算的平均图。该MSE不是后验随机重建的期望误差。合成图形各组独立生成，但形状类别和变化范围共享，不能据此证明真实图像的生成能力。

## 6. 四张图片怎样阅读

所有图均为320×240，不单独拉伸每个小图的对比度。

- **vae-reconstruction**：三行是圆/方/三角；左列原图、中列解码mu、右列后验随机采样重建，展示采样变化。
- **vae-latent-grid**：7×7小图，横轴z0从-2到2，纵轴z1从上方2到下方-2。每格直接解码该坐标，跳过编码器；这是规则网格，不是随机样本或分类标签地图。
- **vae-interpolation**：8幅图从左到右、再换行，线性插值第一张圆与第三张三角的编码mu。只插值潜在坐标，不对输出图片做像素混合。
- **vae-prior-samples**：12个标准正态先验坐标直接解码，未使用测试图进行编码。导出随机状态从6025开始，与训练及评估分离。

二维瓶颈和简单Bernoulli解码器可能生成模糊边界或混合图形；不能保证每个网格坐标都对应清晰的某一类别。这里展示的是潜在空间行为，生成图的视觉效果不能替代独立评估。

## 8. 练习

先固定epsilon手算mu与sigma的导数；再比较同一图的多次后验重建。尝试改变KL权重、logvar范围或潜在维度，同时修改采样与数组形状并重新做梯度检查。用验证集选择配置，保留最终测试集；关注重建质量、KL及先验样本的共同变化，不只追求训练MSE。
